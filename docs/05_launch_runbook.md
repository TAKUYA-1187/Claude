# 05. ゼロから収益化までの完全手順書

最終更新: 2026-08-08
対象: 日本在住・YouTubeアカウントを持っていない状態からのスタート

---

## 今日やること（これだけ先に読む）

順番を間違えると詰まります。**今日は次の3つだけ**やってください。所要 40 分。

1. **Googleアカウントを作る**（チャンネル専用に新規で。私用と混ぜない）
2. **ブランドアカウントでチャンネルを作る**
3. **電話番号による確認を行う** ← **最重要**

### なぜ ③ が最重要か

**確認していないアカウントは15分を超える動画をアップロードできません。**
今回作った動画は全部 2時間24分なので、これをやらないと1本も上げられません。

同時に「カスタムサムネイル」も解禁されます。用意した10枚のサムネイルも、
確認前は設定できません。**ここが実質的なスタートラインです。**

---

## 全体像

収益化までは6つの関門があります。所要期間の目安を添えます。

| # | 関門 | 所要 | 難易度 |
|---|---|---|---|
| 1 | アカウント開設・電話確認 | 1日 | ★☆☆ |
| 2 | チャンネルの体裁を整える | 1日 | ★☆☆ |
| 3 | 10本を公開する | 3〜4週間 | ★★☆ |
| 4 | **登録者1,000人** | **6〜18ヶ月** | ★★★ ← 最大の壁 |
| 5 | 総再生時間4,000時間 | 3〜6ヶ月 | ★☆☆ ← 2時間動画なら楽 |
| 6 | YPP申請・審査・AdSense設定 | 1〜2ヶ月 | ★★☆ |

**この事業のボトルネックは④の登録者1,000人です。**
2時間動画なら **2,000回の完全視聴で4,000時間**に届くので、再生時間はまず問題になりません。
一方 BGM は「つけっぱなしにして去る」使われ方なので登録ボタンが押されにくい。
ここをどう突破するかが全てです（→ フェーズ5）。

## フェーズ1: アカウント開設（Day 1・所要40分）

### 1-1. Googleアカウントを新規作成する

- [ ] https://accounts.google.com/signup で新規作成
- [ ] **私用のアカウントと分ける**（後で人に渡す・売却する可能性、私用メールとの混在事故を避けるため）
- [ ] パスワードは使い回さない
- [ ] **2段階認証を有効にする** ← YPP申請の必須条件。今やっておく

> 💡 **AdSenseアカウントは1人1つだけ**です。すでに別のブログ等で
> AdSenseを持っている場合は、**そのアカウントに紐付けます**（新規作成しない）。

### 1-2. ブランドアカウントでチャンネルを作る

個人アカウントではなく**ブランドアカウント**を選んでください。理由は3つ。

- 1つのGoogleアカウントで**複数チャンネルを持てる**（将来ジャンル別に分けられる）
- **複数人で管理できる**（外注する場合に必須）
- **チャンネル名がGoogleアカウント名と切り離される**（本名が出ない）

手順:
- [ ] YouTubeにログイン → 右上のアイコン → 「チャンネルを作成」
- [ ] 「カスタム名を使う」を選ぶ（＝ブランドアカウント）
- [ ] チャンネル名を英語で入力

**チャンネル名の付け方**

英語圏向けなので日本語は使いません。ジャンルが分かる語 + 覚えやすい語の組み合わせが定石です。

| 良い例 | 理由 |
|---|---|
| `Quiet Hours Music` | 用途が伝わる。検索にも乗る |
| `Lantern Lofi` | 短く、視覚イメージがある |
| `Slow Tokyo Records` | 日本発であることを逆に武器にする |

避けるもの: 数字の羅列、`BGM Channel 2026` のような汎用語だけ、絵文字。

- [ ] ハンドル（@〜）を設定。チャンネル名と揃える

### 1-3. 電話番号による確認【最重要】

- [ ] https://www.youtube.com/verify にアクセス
- [ ] SMS または自動音声で確認コードを受け取る
- [ ] コードを入力

確認できたかは **YouTube Studio → 設定 → チャンネル → 機能の利用資格** で見られます。
「電話による確認が必要な機能」が**［有効］**になっていればOK。

これで解禁されるもの:
- ✅ **15分を超える動画のアップロード** ← 今回の動画に必須
- ✅ **カスタムサムネイル** ← 用意した10枚に必須
- ✅ ライブ配信
- ✅ Content IDの申し立てへの再審査請求

## フェーズ2: チャンネルの体裁を整える（Day 1〜2・所要2時間）

空っぽのチャンネルに動画だけ上げても登録されません。先に器を作ります。

### 2-1. 基本設定

- [ ] YouTube Studio → 設定 → **全般 → 通貨: 日本円（JPY）**
- [ ] 設定 → **チャンネル → 基本情報 → 居住国: 日本**
- [ ] 設定 → チャンネル → 詳細設定 → **「いいえ、このチャンネルを子ども向けとして設定しません」**

> ⚠️ **「子ども向け」に設定すると広告単価が激減します。** BGMチャンネルは
> 子ども向けではないので必ず「いいえ」。ここを間違えると収益が数分の一になります。

- [ ] 設定 → チャンネル → 詳細設定 → **キーワード**に英語で
      `relaxing music, sleep music, study music, lofi, jazz, ambient, background music`

### 2-2. 見た目

- [ ] **プロフィール画像** 800×800px。ジャンルが一目で分かるシンプルなもの
- [ ] **バナー** 2048×1152px（安全領域 1235×338px）。チャンネル名 + 一言
- [ ] **チャンネル説明**（英語で。日本語は書かない）

説明文のテンプレート:

```
Original relaxing music for sleep, study and slow evenings.

Every track here is composed, mixed and mastered from scratch —
no stock loops, no compilations. Long seamless mixes you can
leave running for hours.

New mixes every Tuesday, Thursday and Saturday.

🎧 Best with headphones, low volume.
```

- [ ] **再生リストを4つ**作る（動画を上げる前に器だけ用意）
  - `Sleep Music` / `Study & Focus` / `Work & Cafe` / `Relax & Unwind`

## フェーズ3: 初回アップロード（Day 2〜3）

### 3-1. アップロード前の確認

各動画は **700〜800MB**、2時間24分です。

- [ ] 有線または安定したWi-Fiで（1本あたり10〜30分かかります）
- [ ] PCのブラウザから上げる（スマホアプリは長尺で不安定）
- [ ] 1本上げ終わってから次を上げる

### 3-2. 入力する項目

`out/metadata/<slug>.json` の中身をそのまま貼れます。

| 項目 | 入れるもの |
|---|---|
| タイトル | `title` をコピー |
| 説明 | `description` をコピー |
| サムネイル | `out/thumbnail/<slug>.png` |
| 再生リスト | 用途に合うものを選択 |
| 視聴者層 | **「子ども向けではありません」** |
| 年齢制限 | なし |
| カテゴリ | **音楽** |
| 動画の言語 | **英語** |
| タグ | `tags` の6〜8個 |
| コメント | 許可（すべて許可 or 不適切なものを保留） |

### 3-3. 収益化タブについて

**まだ何も出ません。** 収益化の設定はYPPに参加してからです。
今はグレーアウトしていて正常です。

### 3-4. 最初の3本

いきなり10本上げないでください（→ フェーズ4の警告）。
最初は**用途がバラける3本**を選び、どのジャンルが反応するか見ます。

推奨: `03_piano_and_rain`（王道・検索需要が安定）、
`04_cozy_coffee_jazz`（戦略上の主力）、
`02_deep_sleep_ambient`（再生時間の稼ぎ頭）

## フェーズ4: 運用（Week 1 〜 収益化まで）

### 4-1. 投稿ペース【絶対厳守】

**週2〜4本。1日1本を超えない。**

コードで何本でも作れますが、**投稿ペースが速いと「量産コンテンツ」判定**を受けます。
2025年7月施行の Inauthentic content ポリシーで、これが収益化剥奪の最頻原因です。
実際に「再利用されたコンテンツに関するポリシー違反」で音楽チャンネルが
収益化停止になる事例が報告されています。

### 4-2. 投稿時刻（日本時間）

| 曜日 | 日本時間 | 狙う市場 | ジャンル |
|---|---|---|---|
| 火 | **12:00** | 米国東部 22時 | 睡眠・ピアノ＋雨・海 |
| 木 | **21:00** | オーストラリア 22時 | 睡眠・ヒーリング |
| 土 | **07:00** | 豪州の朝＋米国の夕方 | カフェジャズ・ボサ・集中 |

予約投稿を使えば、実際の作業は好きな時間にできます。

### 4-3. 10本を出し切ったあと

`bgm_studio/tracks.py` の `seed` を変えると別の曲になります。

```python
TrackSpec(slug="01b_lofi_rainy_study", ..., seed=1012)   # 1011 → 1012
```

- [ ] 反応が良かったジャンルを特定する（→ 4-5）
- [ ] そのジャンルの seed 違いを月2〜3本追加する
- [ ] **同じ音源を再アップロードは絶対にしない**

### 4-4. 登録者1,000人を突破する【最大の壁】

BGMは登録されにくいので、意図的に仕掛けます。

**① Shorts を回す（週3本）**

Shortsの再生時間は4,000時間にカウントされませんが、**登録者を集める唯一の現実的手段**です。

```bash
# 長尺の気持ちいい部分から縦型のShortsを切り出す
ffmpeg -ss 300 -t 40 -i out/video/04_cozy_coffee_jazz.mp4 \
  -vf "crop=608:1080:656:0,scale=1080:1920" -c:a copy shorts_04.mp4
```

- 冒頭2秒でジャンルが分かる文字を入れる（例: `2 hours of coffee shop jazz ☕`）
- 概要に `full 2-hour version on the channel`

**② 動画内で登録を促す**

説明文の1文だけ。しつこくしない（BGMで音声CTAを入れるのは逆効果）。

**③ 終了画面を全動画に設定**

同じ用途の別動画へ誘導。連続再生で滞在時間が伸びます。

**④ 再生リストを育てる**

「Sleep Music」再生リストごと再生される状態を作ると、1セッションの視聴時間が跳ね上がります。

### 4-5. 30日ごとに見る数字

YouTube Studio → アナリティクス で:

| 指標 | 場所 | 判断 |
|---|---|---|
| **視聴者の上位の地域** | 視聴者 | US/AU/UK/CA が上位か。低RPM国が多すぎないか |
| **インプレッションのCTR** | コンテンツ | **3%未満ならサムネを差し替える** |
| 平均視聴時間 | コンテンツ | 極端に短い動画は冒頭30秒を疑う |
| トラフィックソース | コンテンツ | 検索/ブラウジング/関連動画のどれで来ているか |
| 登録者の増加元 | 視聴者 | どの動画・Shortsが登録に効いているか |

## フェーズ5: 収益化の条件を満たす

### 5-1. 2段階ある

| 段階 | 条件 | 得られるもの |
|---|---|---|
| **拡充版YPP** | 登録者500人 + 直近90日に公開動画3本 + 直近12ヶ月3,000時間<br>（またはShorts 300万回/90日） | **ファン課金のみ**（メンバーシップ、Super Thanks等） |
| **通常YPP** | **登録者1,000人 + 直近12ヶ月4,000時間**<br>（またはShorts 1,000万回/90日） | **広告収益** ← 本命 |

> ⚠️ **拡充版（500人）では広告収益は得られません。** ファン課金だけです。
> BGMチャンネルで視聴者がSuper Thanksを送ることはほぼ無いので、
> **実質的な目標は通常YPPの「1,000人 + 4,000時間」です。**
> ただし500人時点で申請しておくと、審査の1回目を先に通せる利点はあります。
> 拡充版の提供状況は地域で異なるため、YouTube Studio の収益化タブで実際の
> 表示を確認してください。

### 5-2. 4,000時間の計算

- 2時間24分の動画を最後まで見る人 = 2.4時間
- **1,667人が完走すれば4,000時間**
- 実際は途中離脱があるので、平均視聴30分と仮定すると **8,000回再生**で到達

登録者1,000人のほうが先に詰まります。

## フェーズ6: YPP申請と審査

### 6-1. 申請

- [ ] YouTube Studio → 左メニュー **収益化** → 「申し込む」
- [ ] YPP規約に同意
- [ ] 審査を待つ（**通常1ヶ月以内**に結果が来ます）

### 6-2. 審査で見られるところ

チャンネル**全体**が見られます。1本だけ整えても意味がありません。

- [ ] すべての動画がオリジナルか
- [ ] 同じ音源の使い回しがないか
- [ ] 説明文・サムネイルが動画の内容と一致しているか
- [ ] 投稿ペースが人手運用として自然か
- [ ] 医療的な断定表現がないか（「不眠症が治る」等）

### 6-3. 不承認だったら

| 回数 | 再申請までの待機 |
|---|---|
| 1回目の不承認 | **30日後** |
| 2回目以降 | **90日後** |

**待つだけでは通りません。**「一目で改善が分かる変化」を加える必要があります。

- 説明文に制作情報（BPM・キー・使用機材・制作日）を追記する
- 動画ごとに映像を作り分けていることを明記する
- 疑わしい動画（似た構成が続くもの）は非公開にする

> このリポジトリの音源は**生成コードが丸ごと残っている**ので、
> 制作過程の証明を求められた場合はリポジトリの履歴とシード値を提示できます。

## フェーズ7: AdSense設定【ここで30%変わる】

**YPPに承認されてから**行います。承認前はこの画面が出ません。

### 7-1. AdSenseアカウントを作る

- [ ] YouTube Studio → **収益化** → 「YouTube向けAdSenseに登録する」→ 開始

> ⚠️ **必ずYouTube Studioから作ってください。**
> AdSenseのサイトで直接作ると正しく紐付きません。
> すでにAdSenseを持っている場合はそれを選択します（1人1つまで）。

### 7-2. 米国の税務情報（W-8BEN）【最重要】

**ここを間違えると、アメリカからの収益の30%が引かれます。**
アメリカは本戦略の主戦場なので、収益全体への影響が最も大きい設定です。

- [ ] AdSense → お支払い → 設定 → **米国の税務情報を管理する**
- [ ] 個人 / 非米国人 → **W-8BEN** を選択
- [ ] 氏名・住所を**半角英数字**で入力（全角だとエラー）
- [ ] **外国のTIN欄に「マイナンバー」を入力** ← これを空欄にすると税率が30%のまま
- [ ] 租税条約の適用を申請する → 日本 を選択
- [ ] 「特別条件」で該当項目にチェック

**正しく入力できていれば、源泉徴収率が 0% と表示されます。**
日米租税条約により、日本居住者の YouTube 収益（著作権使用料扱い）は0%です。

- [ ] **有効期限は提出翌年から3年間**。カレンダーに更新日を登録しておく

### 7-3. 住所確認（PIN）

- [ ] 収益が一定額に達すると、Googleから**ハガキでPIN**が届く（通常2〜4週間）
- [ ] AdSenseにPINを入力

> ⚠️ **発行から4ヶ月以内に入力しないと広告配信が停止されます。**
> ハガキは見落としやすいので注意。届かない場合は再発行を申請できます。

### 7-4. 銀行口座の登録

- [ ] AdSense → お支払い → お支払い方法を追加
- [ ] 日本の銀行口座を登録（**口座名義はローマ字**）
- [ ] 1営業日ほどでGoogleから**少額のデポジット入金**がある
- [ ] その金額をAdSenseに入力して口座確認を完了

### 7-5. 実際に振り込まれるまで

- [ ] 収益が **8,000円**（日本のお支払い基準額）を超える
- [ ] 住所確認（PIN）と口座確認が完了している
- [ ] お支払い保留になっていない

条件を満たすと、翌月の21〜26日ごろに振り込まれます。
**8,000円に届かない月は繰り越し**されます。

## タイムラインの現実

| 時期 | 状態 | 収益 |
|---|---|---|
| 1〜3ヶ月目 | 10本公開。ほぼ反応なし | **0円** |
| 4〜6ヶ月目 | 検索から少しずつ流入。登録者100〜300人 | **0円** |
| 6〜12ヶ月目 | 当たり動画が出れば一気に動く。登録者500〜1,000人 | **0円** |
| 12〜18ヶ月目 | YPP承認。広告収益が発生し始める | 月 数千〜数万円 |
| 18〜24ヶ月目 | 動画40〜100本。ストックが効いてくる | 月 数万〜十数万円 |

**最初の半年は収益0円です。ここで大半の人が辞めます。**

BGMは「ストック型」で、1本が半年〜数年かけて伸びます。
逆に言えば、一度伸びた動画は放置しても回り続けます。
短期の成果を求めるビジネスではありません。

## AdSense以外の収益源（並行して仕込む）

音楽の広告単価は全カテゴリでも下位です。同じ制作物で収益源を増やしてください。

| 収益源 | いつ始めるか | 備考 |
|---|---|---|
| **ストリーミング配信** | 動画10本を出した直後 | 24分音源を曲単位に分けてSpotify/Apple Musicへ。ディストリビューター経由 |
| **Content ID登録** | 配信と同時 | 自分の音源を登録すると**他人からの誤申立てが約90%減る** |
| **商用BGMライセンス** | 登録者3,000人以降 | 店舗・飲食店・オフィス向け。Cafe Music BGM channel の主力事業 |
| **メンバーシップ** | 登録者1万人以降 | 広告なし版・先行公開 |

## やってはいけないこと（再掲）

1. **電話番号確認をせずに始めようとする** ← 15分以上上げられません
2. **米国税務情報を空欄・マイナンバー未入力のまま放置** ← 主戦場の収益が30%減
3. **「子ども向け」を「はい」にする** ← 広告単価が激減
4. **1日に何本も投稿する** ← 量産コンテンツ判定で収益化剥奪
5. **同じ音源をタイトル・サムネだけ変えて再アップ** ← 一発でアウト
6. **登録者購入・再生数購入** ← 即BAN。例外なし
7. **医療的効能を断定する**（「不眠症が治る」「432Hzが病を癒す」）
8. **2時間ループにチャプターを付ける** ← スキップを誘発し総再生時間が落ちる
9. **PINハガキを4ヶ月放置** ← 広告配信停止
10. **3ヶ月で結果が出ないと諦める** ← BGMが伸びるのは6ヶ月以降
