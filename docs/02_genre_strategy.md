## 1. 判断の根拠

### 1-1. 「量産系は死んだ」というのが2026年の実勢

複数の分析が一致して指摘しているのは次の点です。

> 汎用的なビートのコンピレーションや、Suno/Udio の生出力をそのまま投げる形式は**もう機能しない**。
> 一方で、**オリジナルの映像を持つ cinematic / sleep / lofi は依然として RPM $3〜$10 を稼いでいる。**

差がついている要因として挙げられているのは —

- **オリジナルの映像**（ストック素材の使い回しでない）
- **キュレーション（曲順・構成の設計）**
- **タイムスタンプ / トラックリスト**
- **物語性・文脈**

つまり **「音源の質」だけでは差がつかず、「1本の動画としての作り込み」で差がつく**段階に来ています。
これは §01 の Inauthentic content ポリシーとも完全に一致します。

### 1-2. Lofi 直球参入がなぜダメか

- Lofi Girl は登録者 **1,400万人超**、Chillhop Music も **329万人**。
- 検索結果の上位は10年近く固定されており、新規チャンネルの動画は表示すらされません。
- 需要が最大 = 競合も最大。**需要の大きさに釣られて参入するのが最頻の失敗パターン**です。

→ 本プロジェクトでも lofi は **10本中1本だけ**にとどめ、しかも「雨」という軸を足して差別化しています。

### 1-3. 雨音・自然音「だけ」がなぜダメか

1. 音源に人間の付加価値を主張しづらく、**Inauthentic content 判定のリスクが全ジャンル中で最も高い**
2. 誰が作っても同じ音になるため、チャンネルのブランドが育たない
3. 広告単価が最も低い層

→ 本プロジェクトでは自然音は必ず**音楽の下に敷くレイヤー**として使い、単体商品にはしていません。

## 2. 動画の「長さ」の設計

### 2-1. 長さごとの役割

| 長さ | 役割 | 備考 |
|---|---|---|
| 8分未満 | ✕ | ミッドロール広告が入らない。作る意味がない |
| 1時間 | 入口 | 検索で拾いやすいが収益効率は低い |
| **2〜3時間** | **収益の主力** | 広告表示回数と完走率のバランスが最良 |
| 8時間 | 再生時間の稼ぎ頭 | 「一晩つけっぱなし」需要。YPPの4,000時間を最速で埋める |
| Shorts | 登録者の獲得装置 | 再生時間には**カウントされない**（§04参照） |

長尺が有利な理由は明確で、**アンビエント系は視聴者が「つけっぱなしにして離席する」**ため、
1本あたりの総再生時間が圧倒的に伸び、アルゴリズムがそれを評価するからです。
「8時間動画1本は、ショート動画100本より多くの再生時間を積む」と表現されるほどです。

### 2-2. 本プロジェクトの選択: 2時間24分

- ユーザー要件「2時間以上」を満たす
- ミッドロール広告を十分な回数入れられる
- 24分のユニーク音源 × 6周。**24分は市販のBGMアルバム1枚ぶんに相当**し、
  「同じフレーズがすぐ戻ってくる」不快感が出ない最低ライン
- 8時間版が欲しくなったら `--repeats 20` にするだけで作れる（同じ音源で20周＝8時間）

### 各ジャンルの音楽的な仕様

音楽的な「らしさ」は、テンポとスケールとコードの選び方でほぼ決まります。

| ジャンル | BPM | スケール/モード | コードの特徴 | リズム |
|---|---|---|---|---|
| Lofi | 70〜85 | 自然的短音階 | ii-V-I に 9th/11th を足して輪郭をぼかす | スイング16%、キック前ノリ・スネア後ノリ |
| Sleep ambient | 45〜60 | 短音階 | 1コードを4小節以上持続。動かさない | リズム楽器なし |
| Piano + Rain | 55〜70 | 長音階 | I-V-vi-IV を長く伸ばす | ルバート気味。休符を多く |
| Cafe jazz | 90〜110 | 長音階 | 循環コード + ii-V、ルートレスボイシング | スイング30%、ブラシ + ライド |
| Bossa nova | 118〜132 | 長音階 | maj7 / min7 中心、半音下行のベース | クラーベ + シェイカー |
| Healing | 40〜55 | ドリアン / sus | sus2・sus4 で3度を避け浮遊させる | リズムなし。鐘のみ |
| Winter jazz | 80〜95 | 長音階 | IV-vi-♭VII-V で暖かく | ブラシ主体、ライド控えめ |
| Fantasy | 75〜90 | ドリアン | 3度を薄くし5度・4度を強調（中世旋法） | ハープのアルペジオ |
| Focus | 55〜70 | ドリアン | min11 を8小節持続。**旋律を入れない** | マリンバの規則的パルス |

> **旋律の有無は用途で決める。** 集中用に旋律を入れると脳が旋律を追ってしまい、
> 逆に集中を妨げます。10番だけ意図的にメロディを排しているのはそのためです。

## 4. 「AIっぽさ」「打ち込みっぽさ」を消すために入れた要素

このリポジトリの音源が既存の量産系と決定的に違うのはここです。

| 要素 | 実装 | なぜ必要か |
|---|---|---|
| **タイミングの揺れ** | 全音符に ±8〜16ms の正規分布ノイズ | 完全にグリッドに乗ると即座に機械だとバレる |
| **和音のばらし** | 和音の各音を 18〜45ms ずらして発音 | 鍵盤を「押さえた」感じが出る |
| **強弱の揺れ** | ベロシティを正規分布で散らす | 一定ベロシティは打ち込みの最大の特徴 |
| **インハーモニシティ** | ピアノの倍音を整数倍から意図的にずらす | 実際の弦の物理現象。これが無いと合成音に聞こえる |
| **倍音ごとの減衰差** | 高い倍音ほど速く減衰させる | 実際の弦・板の挙動 |
| **うなり（ビーティング）** | シンギングボウルの部分音を微妙にデチューン | 「癒し」の正体はこの干渉 |
| **ワウフラッター** | lofi のみ、テープのピッチ揺らぎを再現 | lofi の「アナログっぽさ」の本体 |
| **休符** | メロディに 35〜50% の確率で休符 | BGMは「鳴っていない時間」が命 |
| **密度の波** | セクションごとに 0.55〜1.0 の密度カーブ | 2時間ずっと同じ密度は絶対にもたない |
| **サチュレーション** | tanh で偶数次倍音を付加 | デジタル特有の硬さを取る |

## 5. やってはいけないこと（ジャンル編）

1. **同じ音源を「ジャンル名だけ変えて」複数本出さない。** 一発でポリシー違反。
2. **1日に何本も投稿しない。** コードで量産できても、外形が「mass-produced」になった時点でアウト。
3. **医療的な効能を断定しない。**
   「432Hzが病気を治す」「不眠症が治る」等はポリシー違反かつ広告単価を落とします。
   → 本リポジトリの説明文テンプレートは "for sleep / for focus" と**用途**しか書いていません。
4. **音圧を上げすぎない。** YouTube は -14 LUFS を超えると音量を下げるだけ。得がありません。
5. **自然音単体の動画を作らない。** 差別化不能かつポリシーリスクが最も高い領域です。
