# 07. 動画戦略 — 月100万円までのロードマップ

最終更新: 2026-10-27（新主力 Sleep Piano・子守唄まとめ版・子ども向け Shorts を追加し、カレンダーを更新）

---

## 0. 先に結論

1. **チャンネルの軸を「雑音のない、やさしいメロディ」に絞ります。**
   雨・風・暖炉の音が主役の動画（ノイズ系）は、オーナー自身が「雑音」と感じたものです。視聴者も同じように感じる可能性が高いので、主力から外します。
2. 月100万円には **月190万〜330万回の再生**が必要です。順調でも **2〜3年**かかり、届かないチャンネルの方が多い目標です。保証はできません。
3. 最初の壁は **登録者1,000人**です。打ち手は次の4つです。
   - メロディ主体の長尺を週2本
   - Shorts を毎日1本
   - 長尺の公開は1日1本まで
   - **公開前に必ず人の耳で1分試聴する**（今回の反省）

## 1. 今回の指摘と、何が悪かったか

| 聞こえ方 | 原因 | 直したこと |
|---|---|---|
| 童謡：途中で曲が止まる | 11分ループの最後に**約28秒の無音**が残り、33分で3回止まっていた | コーラス数と速さを先に決め、ループ長にぴったり収めた |
| 童謡：途中からメロディが変わる | 13通りのアレンジを約45秒ごとに切り替え、**転調（±2）とテンポ変更**も入れていた | 調・テンポは固定。アレンジはやさしい4通りだけにして、約1分半ごとに切り替える |
| 童謡：雑音っぽい | ピアノ・ハープの倍音が硬いうえ、検査に合わせて**高音を+3.5dB持ち上げていた** | やわらかいピアノとオルゴールの音色を新しく作った。高音の持ち上げはやめた |
| BGM：途中からメロディが変わる | メロディを毎回その場で作っていて、**同じ旋律が二度と戻らなかった** | 進行ごとにフレーズを作り、繰り返し使う（覚えられる旋律になる） |
| BGM：雑音っぽくなる | 静かな区間では**メロディを止めていた**ので、風・雨の音だけが残った | 静かな区間でもメロディを続ける。風・雨・暖炉の音量も4〜7dB下げた |

**品質検査の盲点：** これまでの自動検査は「音量」「ループのつなぎ目」「帯域」「同じ雑音の繰り返し」しか見ておらず、**無音・急な変化・耳あたりの硬さは見ていませんでした**。
今後は、自動検査に合格したものでも、**1分の試聴版（`out/preview/*.mp3`）をオーナーが聞いてOKを出してから**アップロードします。

## 1.5 「視聴が伸びない」への答え — 高再生の子ども向け動画に倣う

### 今の数字をどう読むか（10/26 時点）

| 数字 | 値 | 読み方 |
|---|---|---|
| 登録者 | 1 | 開設直後なので普通 |
| 28日間の視聴回数 | 6 | 公開から2日。まだ YouTube がほとんど表示していない段階 |
| n02 のクリック率 | 0% | 表示回数が数十回以下の段階では、0% も 10% も誤差 |
| n02 の平均視聴時間 | 5分40秒 | 2回の平均なので判断材料にならない |

**この数字だけで「質が低い」とは判断できません。** 新しいチャンネルは、最初の数週間はほぼ表示されないのが普通です。
ただし、**パッケージ（サムネ・映像・長さ）が弱かったのは事実**です。次の表のとおり、高再生の子ども向け動画とは差がありました。

### 参考動画（Super Simple 日本語「きらきらぼし」5,070万回）との比較

| 要素 | 参考動画 | 旧版（n01・n02） | 新版で変えたこと |
|---|---|---|---|
| 主役 | 顔のあるキャラクター（星） | 抽象的な夜空 | **オリジナルキャラ「Luna（ナイトキャップの眠るお月さま）」** |
| 色 | 明るく彩度の高い色 | 暗い紺・黒 | パステルの藍〜ラベンダー〜桃色 |
| サムネ | キャラ＋太い文字2〜3語＋縁取り | 暗い写真＋細い文字 | **太い丸文字（黄＋濃紺縁）＋桃色バッジ＋キャラ** |
| 長さ | 2〜3分（歌）／まとめ版は30分〜1時間 | 33分 | **1時間**（寝かしつけ用途の定番の長さ） |
| 言語 | 日本語版チャンネルを別に運営 | 英語のみ | **日本語のタイトル・説明を「翻訳」として追加**（同じ動画のまま） |
| シリーズ感 | 全動画で同じキャラ・同じ型 | 曲ごとに映像がばらばら | 10曲すべて Luna＋同じサムネの型で統一 |

### 倣わないもの（できない・やってはいけない）

- **参考動画のキャラクターや見た目をまねること。** 他社の著作物で、商標の問題にもなります。Luna は別デザインのオリジナルです。
- **歌（歌詞を歌う声）。** 参考動画の伸びの大きな理由は歌ですが、合成の歌声は不自然になりやすく、逆効果になる可能性が高いので入れません。日本語の訳詞は著作権が残っている場合があるため、その点でも使いません。
- **3Dアニメの作り込み。** 制作会社の規模が必要です。こちらは「やさしい2Dの動き（揺れる月・きらめく星・流れる雲）」で勝負します。

### 次の一手（効果が大きい順）

1. **新版10本に差し替える**（1時間・キャラ映像・新サムネ）。n01・n02 の旧版は削除します。
2. **日本語の翻訳を全動画に追加する**（Studio → 言語）。日本語で「きらきら星 子守唄」と検索した人にも表示されるようになります。
3. **まとめ版（コンピレーション）を作る**：「Lullabies for Babies — 10曲 1時間／3時間」。子守唄の検索で一番再生されているのはこの型です。10本の公開が終わる 11/21 の次に出します。
4. **子ども向け Shorts**：Luna が揺れる縦動画（30〜45秒）を、公開済みの曲ごとに1本ずつ出します。
5. **曲ごとの小物**：羊（メリーさん）、ボート、橋など、曲が一目でわかる絵を Luna の横に置きます（シリーズ第2弾で）。

### 2週間後（11/9頃）に見る数字

| 数字 | 目標 | 下回ったら |
|---|---|---|
| インプレッションのクリック率 | 4%以上 | サムネの文字・色を変えた版を作り、どちらが良いかを比べる |
| 平均視聴時間（1時間版） | 10分以上 | 冒頭30秒の音量・映像を見直す |
| 日本からの視聴の割合 | 確認するだけ | 多ければ日本語タイトルを主にする |

| 柱 | 内容 | 子ども向け | 配分 |
|---|---|---|---|
| **A. Gentle Piano for Sleep**（新・主力） | やわらかいピアノとオルゴールだけ。雨・風の音なし。1〜8時間 | いいえ | 週1本 |
| **B. Cozy Jazz & Café** | カフェジャズ・ボサノヴァ。環境音はあっても音楽の20dB以上下 | いいえ | 週1本 |
| C. Seasonal | ハロウィン・暖炉・クリスマス。時期の2〜4週間前に出す | いいえ | 時期だけ |
| D. Lullabies for Babies | 童謡10本（1時間・Luna）→ まとめ版 → 子ども向け Shorts | **はい** | 3日おき（11/21まで）、以降まとめ版 |

**A を主力にする理由：**
- オーナーが一番「聞き心地が良い」と感じる方向と一致します（ノイズを嫌う）。
- 童謡で作った「雑音ゼロ・やわらかいピアノ」の仕組みを、そのまま大人向けの睡眠用に使えます。
- 「子ども向け」ではないので、通常の広告・通知・終了画面がすべて使えます。

## 5. 毎回の制作フロー（品質の約束）

1. Claude が生成し、自動検査（音量・つなぎ目・帯域・無音・反復）に合格させる
2. **1分の試聴版をチャットで送る → オーナーが聞いて OK / NG を返す**
3. OK のものだけ、zip（動画＋サムネイル）と投稿手順を送る
4. オーナーが YouTube Studio で予約投稿する（最後のボタンは必ずオーナーが押す）

## 7. 30日・60日・90日の判断

| 時期 | 見る数字（YouTube Studio → アナリティクス） | 判断 |
|---|---|---|
| 30日（11/25頃） | インプレッションのクリック率 | 3%未満のサムネは差し替える |
| | 平均視聴時間 | 長尺で10分未満なら冒頭を見直す |
| | 童謡10本の合計再生 | 1,000回未満なら童謡の追加制作はしない |
| 60日（12/25頃） | A と B のどちらが伸びたか | 伸びた方を週2本に増やす |
| 90日（1/24頃） | 登録者数・再生時間 | 収益化の条件までの残りから、投稿ペースを決め直す |

## 8. 守ること

- AI・自動生成の使用は、アップロード画面の質問に**事実どおり「はい」**と答える
- 1日に長尺を2本以上出さない。同じ音源をタイトルだけ変えて出さない
- 「不眠が治る」「432Hzで病気が癒える」などの効能は書かない
- 童謡は必ず子ども向け「はい」、それ以外は必ず「いいえ」
- 自動検査とオーナーの試聴、**両方の合格**がそろうまで公開しない
