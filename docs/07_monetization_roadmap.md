# 07. 月100万円までの収益化ロードマップ

最終更新: 2026-10-25（n01・n02 公開日）

---

## 0. 先に結論

1. **童謡シリーズだけでは月100万円には届きません。** 予定の10本は出し切りますが、11本目以降は作りません。
   チャンネルを伸ばすのは **「子ども向けではない」長時間BGM**（睡眠・雨・カフェジャズ・暖炉）です。
2. 月100万円は、**月200万〜330万回の再生**が必要な水準です。
   順調に進んで **2〜3年**、届かないチャンネルの方が多い目標です。保証はできません。
3. 最初の壁は **登録者1,000人**（収益化の条件）です。ここまでの打ち手は「長時間BGMを週2本」「Shorts を毎日1本」「1日に公開するのは長尺1本まで」の3つです。

## 1. 「この童謡動画は本当に見られるのか」— 正直な見立て

| 観点 | 童謡（子ども向け） | 長時間BGM（子ども向けではない） |
|---|---|---|
| 広告 | パーソナライズ広告が**出ない** → 単価が大きく下がる | 通常の広告 |
| 登録者への新着通知 | **届かない** | 届く |
| コメント・終了画面・カード | **使えない** | 使える |
| おすすめ表示 | パーソナライズされない | 視聴履歴に応じて出る |
| 競合 | アニメ付きの巨大チャンネル（数千万登録） | 大手はいるが、テーマの切り口で入り込める |
| 動画の長さ | 33分（競合は1〜3時間が多い） | 2時間24分〜10時間 |

- 子ども向け設定は、童謡・子守唄では**法律（COPPA）上の義務**なので、外すことはできません。外した場合は規約違反になり、チャンネルごと処分されるリスクがあります。
- そのため童謡は「検索で少しずつ見られて、再生時間を積む脇役」です。**収益の柱にはしません。**
- **やめる基準**：公開から30日たって、10本合計の再生が1,000回に届かなければ、童謡の追加制作はしません（すでに作った10本は予定どおり出します）。

## 2. 月100万円の逆算

| 項目 | 値 | 根拠 |
|---|---|---|
| 目標 | 月100万円 ≒ **$6,700** | 1ドル150円で換算 |
| 1,000回再生あたりの手取り（RPM） | **$2.0〜3.5** | 長時間の音楽動画・米国中心の場合（`01_market_research.md` §2） |
| 必要な月間再生数 | **約190万〜330万回** | $6,700 ÷ RPM × 1,000 |
| 必要な動画数の目安 | **長尺100本以上 ＋ 大きく伸びる動画が数本** | 1本あたり月2万回 × 100本 |

広告だけに頼らず、同じ音源で次の収入も足します（すべて収益化の後で十分です）。

| 収入源 | 内容 | 始める時期 |
|---|---|---|
| YouTube 広告 | 本線 | 収益化の承認後 |
| YouTube Premium の分配 | 自動で入る | 同上 |
| 音楽配信（Spotify / Apple Music） | 24分のループ音源を配信会社経由で登録。AI・自動生成の扱いは各社の規約に従って申告する | 登録者1,000人前後 |
| メンバーシップ | 広告なしの長時間版など | 登録者1万人以降 |
| 店舗用BGMライセンス | カフェ・美容室向け | 再生実績ができてから |

### 時間の目安

| 段階 | 目安 | 判定 |
|---|---|---|
| 登録者1,000人＋再生時間4,000時間 → 収益化の申請 | 6〜18か月 | YouTube Studio「収益化」タブ |
| 月1万円 | 収益化から数か月 | |
| 月10万円 | 長尺50本前後＋当たり1本 | |
| 月100万円 | 長尺100本以上＋当たり数本、2〜3年 | |

> 2027年2月から、再生時間の条件が 4,000時間 → 8,000時間に上がるという情報があります（第三者の解説記事のみで、YouTube 公式では未確認）。
> 長時間動画は再生時間が積み上がりやすいので、どちらでも詰まるのは「登録者1,000人」の方です。

## 3. チャンネルの3本柱

| 柱 | 役割 | 本数の配分 |
|---|---|---|
| **① 長時間BGM（睡眠・雨・暖炉・カフェ）** | 再生時間と広告収入の主力。子ども向け「いいえ」 | 週2本 |
| **② Shorts（30〜45秒の縦動画）** | 登録者を集める入口。必ず元の長尺動画を「関連動画」に設定 | 1日1本 |
| ③ 童謡・子守唄 | 検索からの脇役。子ども向け「はい」 | 予定の10本で打ち止め |

### 収益化の審査が終わるまで出さない動画

審査では「同じものを大量生産していないか」をチャンネル全体で見られます。音楽の比重が低いものは、承認の後に回します。

| 動画 | 理由 |
|---|---|
| 27_rain_black_screen（黒画面・雨10時間） | 雨音のみ。量産判定のリスクが全ジャンルで最も高い |
| 18_starship_sleep（ホワイトノイズ） | 同上 |
| 19_528hz / 20_focus_40hz | 周波数を前面に出した動画は、効能をうたう誤解を招きやすい。チャンネルの評価が固まってから |

## 6. 30日・60日・90日の判断

| 時期 | 見る数字（YouTube Studio → アナリティクス） | 判断 |
|---|---|---|
| 30日（11/24頃） | インプレッションのクリック率 | 3%未満のサムネは差し替える |
| | 平均視聴時間 | 長尺で10分未満なら冒頭の音量・映像を見直す |
| | 童謡10本の合計再生 | 1,000回未満なら童謡の追加制作はしない |
| 60日（12/24頃） | 視聴者の上位の国 | 米・英・豪・加が上位かを確認 |
| | 伸びたテーマ上位2つ | そのテーマの第2弾（別の曲・別の映像）を作る |
| 90日（1/23頃） | 登録者数・再生時間 | 収益化の条件までの残りから、投稿ペースを決め直す |

## 7. 守ること（収益化を失わないために）

- AI・自動生成の使用は、アップロード画面の質問に**事実どおり「はい」**と答える。隠さない。
- 1日に長尺を2本以上出さない。同じ音源をタイトルだけ変えて出さない。
- 「不眠が治る」「432Hzで病気が癒える」などの効能は書かない。
- 童謡は必ず子ども向け「はい」、それ以外のBGMは必ず「いいえ」。
- 音量（−14 LUFS）、ノイズ、ループのつなぎ目は、毎回 `qa_check.py` の合格を確認してから出す。
