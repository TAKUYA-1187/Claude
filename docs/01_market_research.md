# 01. どの国を狙うか — 市場調査

最終更新: 2026-08-08

---

## 0. 先に結論

| 論点 | 結論 |
|---|---|
| **主戦場** | **アメリカ（US）**。収益の大半はここから出る |
| **戦略的第2位** | **オーストラリア（AU）**。単価が高く、かつ日本からの運用が圧倒的に楽 |
| **無料でついてくる** | イギリス・カナダ・ニュージーランド（英語のまま何もせず取れる） |

| **「AUだけ狙う」** | **不可能かつ非推奨**。理由は §3 |
| **単価の期待値** | BGM/音楽カテゴリの RPM は **$1〜5 / 1000再生** が現実的なレンジ |

## 1. 最初に潰しておくべき誤解

### 誤解①「YouTubeで国を指定して配信できる」

**できません。** オーガニック配信で操作できるのは次の5つだけです。

1. 言語（タイトル・説明文・タグ・字幕・チャンネル概要）
2. 文化的シグナル（サムネの文字、映像の風景、季節感）
3. **投稿時刻**（公開直後のインプレッションがどの時間帯に配られるか）
4. 既存視聴者の地理分布（アルゴリズムは「似た層」に配るので初期構成が固定化しやすい）
5. YouTube Studio の「動画の言語」「デフォルト言語」設定

つまり「オーストラリアを狙う」という戦略は技術的に実行不能です。実行できるのは
**「英語圏全体に向けて出し、投稿時刻でどの国に初動を寄せるか調整する」** だけ。
この前提を外すと、以降の判断が全部ずれます。

### 誤解②「CPMが高い国＝儲かる国」

CPM と RPM は別物です。

- **CPM** = 広告主が広告1000回表示に払う額（YouTubeの取り分45%を引く前）
- **RPM** = あなたの手取り ÷ 総再生数 × 1000（取り分を引いた後、広告が出なかった再生も分母に入る）

音楽カテゴリの実例として、**CPM $4.05 が RPM $2.28 にしかならない**という報告があります
（1再生あたりの広告表示が1.56回しかないため）。
ネット上の「オーストラリアのCPMは $39」といった数字は、**全ジャンル込みの上限値**であり、
BGMチャンネルにそのまま当てはめると 10 倍以上ずれます。

### 誤解③「音楽ジャンルは単価が良い」

逆です。音楽・リラクゼーションは広告主の入札が弱く、**全カテゴリの中でも下位**です。
複数のソースが示す音楽カテゴリの実勢:

| 指標 | 値 | 出典の性質 |
|---|---|---|
| 音楽の1000再生あたり支払い | $0.47 〜 $9.13 | 幅が非常に広い |
| 音楽チャンネルの典型RPM | **$1.5 〜 $3** | 中央値に近い |
| 長尺音楽コンテンツのRPM | **$1.50 〜 $5.00** | 本件に最も近い条件 |
| オリジナル映像付きの sleep/lofi | $3 〜 $10 | 上振れ条件（差別化できている場合） |
| Art Track（配信会社経由） | 平均 $5.64 | 別ルートの収益 |
| Content ID 経由の申立て | 平均 $0.87 | 参考 |

**このプロジェクトの計画値は RPM $2.0（保守）〜 $3.5（強気）** に置くのが妥当です。

> ⚠️ 注意: 上記のうち「国別CPMランキング」系の数値は、出典がSEO目的のブログ記事群で、
> 一次データではありません。**自分のチャンネルのYouTube Studio > 収益 > 地域別RPM**
> が唯一の正確な情報源です。運用開始90日後に必ず実測値へ差し替えてください。

## 2. 国別の評価

### 2-1. 単価（CPM）のランキング

複数ソースで一貫して上位に来る国（全ジャンル込みの相対順位として参照）:

1. オーストラリア
2. アメリカ
3. カナダ
4. ニュージーランド
5. スイス / ノルウェー / デンマーク

ノルウェーやスイスは1人あたり単価でアメリカを上回ることがありますが、
**市場規模が小さすぎて総額では勝負にならない**、という点が重要です。

### 2-2. 「単価 × 規模」で見た期待値

BGMは英語話者ならどの国でも同じ動画が刺さるので、
**期待収益 ≒ 到達可能人口 × 単価** で比較するのが正しい見方です。

| 国 | 人口規模の目安 | 単価の相対 | 期待値の相対 | 位置づけ |
|---|---|---|---|---|
| **アメリカ** | 約3.4億 | 高 | **圧倒的1位** | 主戦場 |
| イギリス | 約6,900万 | 中〜高 | 2位グループ | 自動でついてくる |
| **オーストラリア** | 約2,700万 | **最高クラス** | 3位グループ | 戦略的に重要（§3） |
| カナダ | 約4,100万 | 高 | 2位グループ | 米国最適化がそのまま効く |
| ニュージーランド | 約520万 | 高 | 小さい | おまけ |
| ドイツ・北欧 | — | 高 | 中 | 歌詞が無いので言語障壁ゼロ。放置で取れる |
| インド・ブラジル等 | 巨大 | **極めて低い** | — | **平均RPMを引き下げる要因** |

アメリカとオーストラリアの人口差は **約12倍**。
オーストラリアの単価が仮に1.2倍高くても、期待値の差は **約10倍** 残ります。

## 3. オーストラリアをどう位置づけるか

### 主戦場にはしない（が、捨てない）

**主戦場にしない理由**

1. **市場規模が足りない。** AU人口2,700万はUSの約1/12。単価が高くても総額で追いつきません。
2. **AUだけを狙う手段が存在しない。**（§1の誤解①）
   投稿時刻をAUに寄せた瞬間、規模が10倍あるUSの初動を捨てることになります。
3. **AU固有のニッチが薄い。** BGMに「オーストラリアならでは」の需要要素がほぼありません。

### それでもAUが重要な理由 ← ここが本題

**日本在住のクリエイターにとって、オーストラリアは「深夜労働なしにプライムタイムを取れる唯一の英語圏」です。**

| 現地時間 | 日本時間（JST, UTC+9） | 備考 |
|---|---|---|
| シドニー 22:00（AEST, UTC+10） | **21:00** | 睡眠BGMのゴールデンタイム |
| シドニー 22:00（AEDT, UTC+11・夏時間） | **20:00** | 同上 |
| ニューヨーク 22:00（EST, UTC-5） | **翌12:00** | 昼。作業しやすい |
| ロサンゼルス 22:00（PST, UTC-8） | **翌15:00** | 午後。作業しやすい |
| ロンドン 22:00（GMT） | **翌07:00** | 早朝 |

つまり —

- **US向けの睡眠BGMは「日本の昼」に投稿すればいい**（深夜作業は不要）
- **AU向けは「日本の夜21時」でちょうど良い**

**結論: US を主軸に据えつつ、AU を週1枠のサブスロットとして使う。** これが日本発チャンネルの最適解です。

## 4. 日本人が海外向けBGMで成功した実例

### Cafe Music BGM channel（BGMC Records）

- 2013年結成の**日本の4人編成バンド**（ピアノ・ギター・ベース・ドラム）
- YouTubeで **200カ国以上・のべ1,500万人** に視聴されている
- ほぼ全曲がメンバーによる**オリジナル楽曲**
- 公式サイトを **英語・日本語・繁体字・スペイン語・韓国語** の5言語で展開
- YouTube広告収入だけでなく、**店舗・飲食店・病院・オフィス向けの商用BGMライセンス事業**（BGM Station）に横展開

**ここから学ぶべき3点**

1. **日本人であることは不利ではない。** BGMに歌詞は無く、言語障壁が存在しない。
2. **オリジナル楽曲であることが生命線。**（→ §5 のポリシー対応に直結）
3. **AdSense単体で終わらせない。** 商用ライセンス・配信（Spotify等）へ広げてこそ事業になる。

## 5. 収益化ポリシー — ここが最大のリスク

### 2025年7月15日「Inauthentic content（非本物コンテンツ）」ポリシー

2025年7月9日に発表され、**7月15日から適用**。
従来の「Repetitious content（反復コンテンツ）」が **「Inauthentic content」に改称・再定義**されました。

**対象になるもの**
- 大量生産（mass-produced）された動画
- 反復的（repetitious）で、独自の視点や付加価値が無いもの
- ロボット音声のスライドショー、AIアバターのニュース風動画、同じ型を延々繰り返すチャンネル

**重要な明確化**
- **AIの使用そのものは禁止ではありません。** 「AIを使った=収益化不可」ではない。
- AI支援コンテンツも、**オリジナルで、人の手で丁寧に編集されていれば**収益化可能。
- BGMチャンネルは通過すべき審査が5つあります:
  ① Inauthentic content ② Reused content ③ AI開示 ④ 広告主フレンドリー ⑤ Content ID

### BGMチャンネルが構造的に危険な理由

BGMは (a) 音が主で映像が静的、(b) 同じ型の反復が本質、(c) フリー素材を束ねるだけでも成立してしまう
— という3点で、**何もしなければ「量産・反復」の外形要件に自然に当てはまってしまいます。**

### 危険 / 安全の判定表

| 挙動 | 判定 | 理由 |
|---|---|---|
| 同じ音源をサムネ・タイトルだけ変えて複数本アップ | **致命的にNG** | Inauthentic の典型例 |
| フリー素材サイトのBGMをそのまま束ねる | **NG** | 他の数千チャンネルと同一音源。オリジナリティ皆無 |
| AI生成音源をライセンス未確認で毎日大量投下 | **NG** | 量産要件＋ライセンス不備の二重リスク |
| 1日3〜10本の投稿 | **NG** | 「mass-produced」の最も分かりやすいシグナル |
| ストック映像の使い回し＋文字差し替えのみ | **NG** | テンプレート量産判定 |
| 「不眠症が治る」「432Hzが病を癒す」等の断定 | **NG** | 医療系誤情報＋広告主フレンドリー違反 |
| **自作曲＋固有のアートワーク＋固有のトラックリスト** | **安全** | 人の付加価値が明示的に存在する |
| **週2〜4本の一定ペース、シリーズ設計あり** | **安全** | 人手運用として自然 |
| **動画ごとに作り分けた映像** | **安全** | 映像レイヤーでも独自性を主張できる |
| 説明文に**曲情報・制作メモ**を書く | **安全** | 「人が作った証拠」の外形化 |

### 本プロジェクトがこの要件をどう満たすか

このリポジトリで生成する10本は、**すべての音・すべての映像を一から合成**しています。

- 既存の音源素材・ループ素材・ストック映像を**一切使っていない**
- 10本すべてがジャンル・BPM・キー・楽器編成・映像シーンが異なる
- 生成に使ったソースコードが丸ごと残っており、**制作過程を証明できる**
- 同じ音源の使い回しをしていない

→ 「mass-produced / repetitious」の外形要件に当てはまりません。

**ただし運用側の注意:** 投稿ペースを守ること（1日に何本も上げない）。
コードで量産できるからといって毎日投下すると、そこで一発でアウトになります。

## 6. 収益化までの条件（2026年時点）

| ルート | 条件 |
|---|---|
| 通常 | **登録者1,000人 + 直近12ヶ月の総再生時間4,000時間** |
| Shorts | **登録者1,000人 + 90日間で1,000万Shorts再生** |
| 早期アクセス | 登録者500人 + 公開動画3本 + 90日で3,000時間（またはShorts 300万再生）※機能限定 |

その他、二段階認証の有効化、コミュニティガイドライン違反の警告が無いこと、AdSense連携が必要。

**BGMチャンネルのボトルネックは「再生時間」ではなく「登録者1,000人」です。**
2時間動画なら、たった **2,000回の完全視聴で4,000時間** に届きます。
一方でBGMは「つけっぱなしにして去る」使われ方なので、登録ボタンが押されにくい。
→ 対策は §「04_upload_playbook」の Shorts 戦略へ。

## 7. 収益シミュレーション

前提: RPM $2.5（音楽長尺の中央値付近）、US中心で視聴者が構成された場合。

| シナリオ | 月間再生数 | 月間広告収入 | 到達の目安 |
|---|---|---|---|
| 保守 | 10万 | **約 $250** | 動画10本・運用6ヶ月 |
| ベース | 50万 | **約 $1,250** | 動画40本・運用12ヶ月 |
| 強気 | 200万 | **約 $5,000** | 動画100本・運用24ヶ月＋当たり動画1本 |

**注意すべき現実**

- BGMは1本が長期間かけて伸びる「ストック型」。最初の3ヶ月はほぼ動きません。
- 収益化条件を満たすまでは **$0**。ここで大半の人が辞めます。
- AdSense単体だと単価が低い。**Spotify/Apple Musicへの配信、商用BGMライセンス**を
  最初から視野に入れると、同じ制作物で収益源が3系統になります（Cafe Music BGM channel の実例）。

## 8. 90日で必ずやること（実測に切り替えるため）

1. YouTube Studio > アナリティクス > **視聴者 > 上位の地域** を確認
   → 想定どおり US/AU/UK/CA が上位に来ているか
2. **収益 > 地域別RPM** を確認
   → 本ドキュメントの推定値を実測値に置き換える
3. 低RPM国の比率が高すぎる場合
   → サムネの文字・映像の文化的シグナルを英語圏寄りに振り直す
4. 投稿時刻ごとの初動（公開2時間のインプレッション）を比較
   → US枠 / AU枠 のどちらが効いているかを判定
