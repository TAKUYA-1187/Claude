# せどり実務ノート 運用マニュアル

ブログ運営の方針・手順・記事計画は、すべてこのファイルにまとめる（ChatGPT時代の管理表・実行記録・運用メモは置き換え済み）。

---

## 1. なぜ方針を変えたか

| 問題 | 事実 | 対応 |
| --- | --- | --- |
| WordPress.com の停止 | WordPress.com の利用規約は「アフィリエイトへの送客を主目的とするブログ」や「検索エンジン向けに書かれたブログ」を禁止している。12サイト＋機械生成の下書き量産は、この規約に正面から当たる | 再審査はしない。通っても同じ運用なら再停止される。月間PVは3サイト合計で約28と少なく、失う資産はほぼない |
| AIが公開まで届かない | ChatGPTはWordPressへのログインで止まり、ファイルは増えたが公開0件・収益0円だった。Claudeのクラウド環境からも WordPress.com には接続できない | 記事をこのリポジトリに書いて push すれば、Cloudflare Pages が自動で公開する仕組みに変えた。**Claudeが執筆から公開まで1人で完結できる** |
| テーマの分散 | 家族・ペット・EC道具の3テーマは、運営者の実体験に基づいていない | 運営者が実際にやっている**買取せどり**の1サイトに集中する。自作の価格比較ツールと、経理の自動化という実データがあり、他のブログにない一次情報になる |

## 2. 仕組み

```
Claude が記事を書く（blog/src/content/posts/*.md）
  → ローカルでビルド・スマホ幅の表示確認・計算検証
  → git push（ブランチ claude/nifty-thompson-99o7m3）
  → Cloudflare Pages が自動ビルド → 公開
```

- サイト本体：Astro（静的サイト）。表示が速く、サーバー代0円
- 標準装備：目次、PR表記（`pr: true` で記事冒頭に表示＝ステマ規制対応）、構造化データ、サイトマップ、RSS、運営者情報、プライバシーポリシー、お問い合わせ
- 設定の変更箇所は `src/site.config.ts` の1か所だけ（サイト名・URL・運営者名・お問い合わせURL）

### ① Cloudflare Pages をリポジトリにつなぐ（最優先・約10分）

アカウント登録だけでは公開されない。次の手順で「このリポジトリの記事を公開する設定」を作る。画面の表示名は多少違うことがある。

1. Cloudflare のダッシュボードで、左メニューの「Workers & Pages」（または「Compute (Workers)」）を開く
2. 「作成」（Create）を押し、「Pages」タブを選ぶ
3. 「既存の Git リポジトリをインポート」（Import an existing Git repository）を押す
4. 「GitHub に接続」を押す。GitHub の画面に移ったら「Install & Authorize」を押す（対象は「All repositories」でも、`Claude` だけを選んでもよい）
5. リポジトリ一覧から `Claude` を選び、「セットアップを開始」（Begin setup）を押す
6. 次の4か所だけ入力する（ビルドコマンドと出力先は、プリセットを選ぶと自動で入る）

   | 項目 | 値 |
   | --- | --- |
   | プロジェクト名 | `sedori-note` |
   | 本番ブランチ | `claude/nifty-thompson-99o7m3` |
   | フレームワーク プリセット | `Astro` |
   | ルートディレクトリ（「詳細設定」「Advanced」の中） | `blog` |

7. 「保存してデプロイ」（Save and Deploy）を押す

終わったら、Claude に「接続した」と伝える。ビルドの成否は Claude が GitHub 側から確認できる。公開URLは通常 `https://sedori-note.pages.dev`。プロジェクト名が使えず別の名前にした場合は、その名前を伝える。

### ② ASP にサイトURLを登録する（① の後）

A8.net・もしもアフィリエイトに登録したサイトURLが WordPress.com のもの（停止中）なら、審査に落ちるため新しいURLに変える。

- A8.net：管理画面の「登録情報」→「サイト情報の登録・変更」
- もしもアフィリエイト：管理画面の「サイト管理」（サイト追加）

メニュー名は変わることがある。見つからない場合は、画面の表示を Claude に送れば案内する。

その後、もしもで「Amazon」「楽天市場」のプロモーションに提携申請する。

### ③ お問い合わせフォームを作る（急ぎではない・約3分）

Claude の環境からは Google フォームを作れない（接続できる Google の機能がドキュメント・スプレッドシート・スライドまでのため）。AdSense 申請（記事15本前後）までにあればよい。

1. スマホかPCで https://docs.google.com/forms/ を開く
2. テンプレート一覧の「連絡先情報」を押す（名前・メール・コメントなどの入ったフォームが自動で作られる）
3. 右上の「送信」→ リンクのマーク（🔗）→「URLを短縮」にチェック →「コピー」
4. コピーしたURLを Claude に送る（Claude がサイトに設定する）

### ④ ChatGPT の定期タスクを止める（任意）

放置しても新しいサイトに影響はない。ChatGPT から報告が届き続けるのが気になる場合だけ、ChatGPT に次の一文を送る。

> 毎日のタスク「ブログ365日・月100万円｜重点3サイト日次運用」を削除してください。

### ⑤ 独自ドメインを取る（記事15本前後になったら）

Google AdSense は独自ドメインが必要。Cloudflare Registrar なら原価（.com で年1,500円前後）で取得でき、Pages にそのまま接続できる。

## 4. 収益化ロードマップ

月100万円は、自分の商品を持つ上位ブロガーの水準。アフィリエイトだけでは届きにくいため、段階ごとに収益源を積み上げる。

| 段階 | 目安 | やること | 収益源 |
| --- | --- | --- | --- |
| 1 | 記事1〜15本 | 基礎記事で「買取せどり」の検索を取る。ASP登録 | Amazon・楽天の商品リンク |
| 2 | 記事15〜40本 | 独自ドメイン・AdSense。高単価の比較記事 | クレジットカード、会計ソフト（A8.net） |
| 3 | 記事40本〜 | 月次の実績公開で信頼を積む。メール・LINE登録 | 高単価案件＋リスト |
| 4 | 読者が付いてから | 自作の価格比較ツール・仕入れ基準テンプレートを商品化 | 自社商品（ここが月100万円の本線） |

投稿ペースは**週2〜3本**にする。1日に大量投稿すると、WordPress.com 停止と同じ「機械生成の量産」と判定され、Googleの検索順位も落ちる。本数より、一次情報と正確な数字で勝つ。

## 6. 記事の品質ルール

- 数字・手数料・規約は、根拠（公式ページ・運営者の実データ）がある内容だけ書き、確認日を入れる
- 体験談・実績は、オーナーから受け取った事実だけを書く。**作らない**
- アフィリエイトリンクを入れた記事は `pr: true`（PR表記が自動で出る）。リンクには `rel="sponsored"` を付ける
- 「誰でも稼げる」「確実に儲かる」などの表現は使わない
- 公開前に毎回、次を確認する：ビルド成功／スマホ幅（390px）で横はみ出しなし／計算ツールや表の数字の検算
