買取せどりの利益は、仕入れた時点では決まりません。**買取店に届いて、査定が終わった時点**で決まります。

その間に利益を削るのが、送料と、輸送中の傷による減額です。どちらも梱包と発送のやり方でかなり防げます。この記事では、送料を下げる同梱の考え方と、減額を防ぐ詰め方を手順にまとめます。

<div class="summary-box">

**この記事の要点**

- 送料は箱単位でかかる。1箱にまとめる点数を増やすほど、1点あたりの送料が下がる
- 減額の多くは「外箱の傷・つぶれ・汚れ」。商品の箱を守る詰め方をする
- 発送前に、中身と状態を写真に残す。減額されたときの確認材料になる

</div>

## 送料は「1箱」にかかる：同梱で1点あたりを下げる

買取店への送料は、商品1点ごとではなく**1箱ごと**にかかります。送料600円の箱に1点だけなら1点あたり600円、5点入れれば120円です。

| 1箱の点数 | 1点あたりの送料（1箱600円の場合） |
| --- | --- |
| 1点 | 600円 |
| 3点 | 200円 |
| 5点 | 120円 |
| 10点 | 60円 |

利益の薄い商品は、1点で送ると赤字でも、まとめると黒字になることがあります。具体的な計算は[買取せどりの利益計算（計算ツール付き）](/posts/kaitori-sedori-profit-calc/)で試せます。

仕入れの段階で「この箱に何点入れて送るか」を決めておくと、送料を見込んだ仕入れ判断ができます。なお、一定の点数や金額以上で送料を負担してくれる買取店もあります。その場合は、条件を満たす量までまとめてから送るのが基本です。

### 箱のサイズは「3辺の合計」と重さで決まる

宅配便の料金は、箱の縦・横・高さの合計と重さで決まるのが一般的です。商品に対して大きすぎる箱を使うと、そのぶん送料が上がり、中で商品が動いて傷の原因にもなります。

- 商品を並べて、すき間が少し残るくらいの箱を選ぶ
- よく送る組み合わせのサイズの箱を、何種類か用意しておく
- 重さの上限に近いときは、[デジタルスケール](aff:pack-scale)で量ってからサイズを決める

## 減額を防ぐ詰め方

新品・未開封での買取は、**商品そのものだけでなく外箱の状態**も査定されます。つぶれ、へこみ、角の折れ、シール跡、汚れは、減額の対象になることがあります。

### 詰め方の手順

1. **箱の底に緩衝材を敷く**：落下の衝撃は底から来ます
2. **重いもの・大きいものを下に置く**：軽い商品を上にして、重さで押しつぶさない
3. **商品どうしがこすれないようにする**：1点ずつ袋に入れるか、間に緩衝材を挟む
4. **すき間を[緩衝材](aff:pack-cushion)で埋める**：箱を軽く振って、中で動かなければOK
5. **上にも緩衝材を置いてから閉じる**：ふたの上からの圧力を受け止めます
6. **[梱包用テープ](aff:pack-tape)で、箱の合わせ目をしっかり閉じる**：底が抜けないよう、底面も十字に貼ると安心です

### やってはいけないこと

- **商品の箱に直接テープや伝票を貼る**：はがした跡が減額の原因になります
- **緩衝材なしで詰める**：輸送中に商品が動き、角がつぶれます
- **濡れる可能性を放置する**：雨の日の配送に備え、商品を袋に入れておくと安全です

## 発送前のチェックリスト

- [ ] 買取申込の内容と、箱の中身の点数・商品が一致している
- [ ] 各商品が買取条件（未開封・付属品・状態）を満たしている
- [ ] 申込書や同梱が必要な書類を入れた
- [ ] 中身と外箱の状態を写真に残した
- [ ] 箱が中で動かず、底と合わせ目を閉じた

### 写真を残す理由

発送前に、商品の外箱の状態と、箱に詰めた様子を写真に撮っておきます。減額や「商品が足りない」という連絡が来たときに、発送時点の状態を確認する材料になります。減額にあったときの確認の流れは、[減額・価格下落にあったときの対処法](/posts/kaitori-price-drop/)で解説しています。

## まとめ

- 送料は箱単位。仕入れの段階で「何点まとめて送るか」を決める
- 箱は商品に合ったサイズを選び、すき間を緩衝材で埋めて商品を動かさない
- 商品の箱には何も貼らない。発送前に写真を残す

梱包の手間は、減額1回ぶんの損失で簡単に元が取れます。最初に資材と手順をそろえておくのがおすすめです。
