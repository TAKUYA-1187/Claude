# 大型OEM リサーチ表（神田式）

`最新リサーチ表_大型OEM_2026-09-24.xlsx` が成果物です。前回リストの40候補を同じ条件で試算し、利益率15%以上（広告10%・返品4%・保管・出荷作業・送料・関税控除後）の8商品をリサーチ表に載せています。

| シート | 内容 |
| --- | --- |
| サマリー | 結論・厳選8商品の損益・次にやること |
| リサーチ表(15%以上) | 競合・1688検索リンク・梱包・送料・損益・月利・感応度・付加価値・レビュー要約 |
| レビュー分析 | 高評価／改善要望（優先度 高・中・低）と当社の対応、出典 |
| 月利100万・年商5億計画 | 月利100万円に必要な月販、SKU展開・併売での年商試算 |
| 全40候補スクリーニング | 40候補の判定（◎15%以上／△条件付き／×除外）と理由、損益分岐の送料・仕入単価 |
| 前提条件 | 為替・立米単価・国内送料表・手数料率など（青字を書き換えると全体が再計算） |
| 出典 | 参照したURL |

## 注意

- Amazon.co.jp と 1688.com の商品ページは作業環境のネットワーク制限で直接開けず、競合情報は検索結果で確認できた範囲です。1688の単価・梱包寸法・月販は推定値（黄色セル）なので、実見積・実測で上書きしてください。
- 送料は天瞳の送料資料が未共有のため仮置きです。`前提条件` の黄色セル（立米単価・国内送料表・保管料・出荷作業料）を差し替えると判定が確定します。

## 作り直す場合

```bash
python3 build_workbook.py styled.xlsx            # 書式・数式つきで出力（計算結果は未格納）
cp styled.xlsx computed.xlsx                     # LibreOffice Calc で computed.xlsx を再計算して保存
python3 inject_values.py styled.xlsx computed.xlsx out.xlsx   # 計算結果を書式つきの方に書き戻す
```

データは `research_data.py` にあります。

## v2（2026-09-25）天瞳リサーチ表形式・68候補の商品化判断

成果物 `最新リサーチ表_天瞳形式_v2_2026-09-25.xlsx` はチャットで直接お渡ししています。このリポジトリは公開設定で、Excelには天瞳のリサーチ表テンプレートがそのまま入っているため、Excel自体はコミットしていません（`v2/*.xlsx` は `.gitignore` 済み）。

- 68候補（前回40＋今回28）を同じ条件で再計算しました。判定は「テンプレ利益率30%以上かつ実質利益率（広告5%）15%以上」でGOです。
- テンプレートの利益率には広告費・返品・保管・出荷作業・売上消費税が入らないため、実質より約20ポイント高く出ます。前回の「15%以上」基準はテンプレ上だと実質赤字になり得ます。

| シート | 内容 |
| --- | --- |
| 00_結論 | 要点、採用ラインナップ、年商5億の到達見込み、次にやること |
| 01_商品化判断_総合 | 68候補のテンプレ利益率・実質利益率（広告10%／5%）・数値判定・最終判定・競合・差別化 |
| 02_1位獲得戦略 | 採用8品の狙うノード、現在の上位、勝ち筋、差別化仕様、価格、1位ラインの月販 |
| 03_年商5億ロードマップ | 11品の1〜3年目の月販・年商・年利、他モール上乗せ、必要在庫資金 |
| R01〜R08 | 天瞳テンプレートに競合2社・レビュー分析（優先度付き）・判定メモを記入し、自社企画品の収益試算ブロックを追加 |
| 前提条件 | テンプレートの計算値、実質試算の追加パラメータ、判定基準、国内送料表（仮置き） |
| 梱包明細 | 1行＝1個口。送料・CBMを自動計算 |
| 出典 / テンプレート(原本) | 参照URL／未記入のテンプレート（原本のまま） |

### 作り直す場合

```bash
cd oem_research/v2
python3 build_v2.py <天瞳リサーチ表.xlsx> styled.xlsx        # テンプレートを読み込み、書式・数式つきで出力
cp styled.xlsx computed.xlsx                                # LibreOffice Calc で computed.xlsx を再計算して保存
python3 ../inject_values.py styled.xlsx computed.xlsx out.xlsx
```

データは `v2/data_v2.py` にあります。
