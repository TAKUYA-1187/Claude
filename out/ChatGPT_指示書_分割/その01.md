## 1. ChatGPT へ：あなたの役割

YouTube チャンネル「Quiet Hours Music」（静かなピアノ・オルゴールの音楽）の動画を、日本と海外の両方から
たくさん見てもらえるように仕上げて、YouTube Studio で予約投稿してください。
音楽と動画（mp4）は Claude が作り、音量・雑音・無音の検査に合格しています。あなたの担当は次の 4 つです。

1. **絵**：動画ごとに、メロディに合う「背景（文字なし）」と「サムネイル（文字入り）」の 2 枚を作る
2. **動画**：あなたの背景と、Claude の動画の音声を組み合わせて、最終の動画を作る
3. **予約投稿**：YouTube Studio で、決められた日時・設定で予約する
4. **多言語化**：6 か国語のタイトルと説明を追加する

## 2. 必ず守ること

- 長尺動画は **1 日 1 本まで**。下の「4. 動画ごとの指示」の日時（日本時間）以外に公開しない
- 「改変されたコンテンツ／AI の使用」は **すべて「はい」**（絵と編曲に AI を使っているため）
- 「子ども向け」は動画ごとの指定どおり（子守唄は「はい」、クリスマス・冬は「いいえ」）
- タイトル・説明・タグは、zip の中の `.txt`（英語）を **そのまま** 使う。書き換えない。
  特に「眠れる」「治る」「不安が消える」など、健康効果をうたう言葉を足さない
- 音声は加工しない（音量・音質は検査済み）
- 同じ動画を二重に上げない。すでに予約済みの動画は飛ばす
- 実在のキャラクター・ブランド・画家に似せた絵を作らない。人の顔は描かない
- 指示に無い日（11/4・11/11・12/11）は空けておく（Claude がまだ作っていない動画の枠）

## 3. 作業の手順（1 本ずつ、公開日の早い順に）

### 3-1. 絵を 2 枚作る

共通のルール：
```

YouTube チャンネル「Quiet Hours Music」の動画の絵を1本ずつお願いします。
音楽は Claude が作っています（録音したピアノ・オルゴール・鈴、雑音なし、A=432Hz）。
1本ごとに「どんな音楽か」を書くので、その音楽を聞いた人が「この絵だ」と感じる絵にしてください。

毎回 2 枚つくってください。

■ 1枚目：動画の背景（文字なし）
- 16:9 横長、1920x1080 以上
- 文字・数字・ロゴ・署名・透かしを一切入れない
- 1時間以上ずっと映るので、落ち着いて見ていられる絵。主役は画面の右側、左側は空・遠景など静かに
- 空や暗い部分を少し広めに残す（Claude が星・雪・光の粒をゆっくり動かして重ねます）
- 細かすぎる模様や、強いコントラストの細い線は避ける（動画の圧縮で崩れるため）

■ 2枚目：サムネイル（文字入り）
- 1枚目と同じ場面・同じ色調で、16:9 横長、1280x720 以上
- 主役は右側、文字は左側 45% に置く（主役に文字を重ねない）
- タイトル：大文字の上品なセリフ体（Cinzel / Trajan のような書体）、太め、クリーム色 #F8ECD4、
  柔らかい影で背景から浮かせる。1〜2行。スマホの小さい表示（横 160px）でも読める大きさ
- 副題：タイトルの下に、字間を広くとった細めのセリフ体の大文字、両側に細い横線
- 左下：時間のバッジ（角の丸い枠線、半透明の濃い紺の地にクリーム色の文字）
- バッジの下に小さく：QUIET HOURS MUSIC
- 指定した文字以外は入れない。スペルを1文字ずつ確認してから出力する
- 色は絵ごとに変えてよいが、文字の色と書体はすべての動画で同じにする（チャンネルの統一感のため）

■ 共通の画風
- やわらかい水彩とガッシュ、絵本のような上質さ、紙の質感、繊細な線
- 夜か夕暮れ。あたたかい光（ランプ・ろうそく・月）が1つあり、見る人がほっとする
- 人の顔は描かない。動物は眠っているか、静かに休んでいる
- 実在の作品・キャラクター・ブランド・画家に似せない。完全なオリジナル
- 子守唄の動画は「赤ちゃんと親が安心する」かわいさ、クリスマスの動画は「大人も家族も楽しめる」上品さ

■ 音楽と絵の合わせ方（大事）
- ゆっくりした 3 拍子・6/8（ゆりかごのリズム）→ 丸い形、ゆれるもの（ゆりかご、揺れる枝、波）
- 鈴の入った明るい曲 → 金色のきらめき、あたたかい暖色、そり・鈴・リボン、少し動きのある構図
- 静かなピアノ（やすらぎ）→ コントラスト低め、深い紺やすみれ色、光源は1つだけ、余白を大きく
- オルゴール → 小さな木のオルゴールや雪の玉など「小さくて光るもの」が主役、青緑やばら色の夜
- 旋律が高く澄んでいる曲 → 星・月・澄んだ空気。低く温かい曲 → 暖炉・ランプ・木の家
```

- 背景：文字なし、1920x1080 → ファイル名 `<記号>.png`
- サムネイル：文字入り、1280x720 → ファイル名 `<記号>_thumb.png`
- サムネイルの文字は英語（世界中で読めるように）。**スペルを 1 文字ずつ確認**し、違っていたら作り直す
- 「絵」の欄が「そのまま」の動画は、すでにあなたの絵が入っているので作らない

### 3-2. 動画を作る（あなたの背景を入れる）

オーナーから受け取った zip の `.mp4` から音声をそのまま取り出し、あなたの背景と組み合わせます。
```
ffmpeg -i <記号>.mp4 -vn -c:a copy audio.m4a
ffmpeg -loop 1 -framerate 2 -i <記号>.png -i audio.m4a \
  -vf "scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,format=yuv420p" \
  -c:v libx264 -preset veryfast -tune stillimage -crf 18 -r 2 \
  -c:a copy -shortest -movflags +faststart <記号>_final.mp4
ffprobe -v error -show_entries format=duration -of csv=p=0 <記号>_final.mp4
```
- 長さが元の動画と同じ（1 時間 = 3600 秒、2 時間 = 7200 秒、±1 秒）ことを確認する
- ffmpeg が使えない・途中で止まる場合：背景画像をオーナーに渡し「Claude に渡してください」と伝える。
  Claude が、星や雪・光をゆっくり動かした動画に作り直して返します（こちらの方が仕上がりは良い）。
  公開まで 2 週間以上ある動画は、こちらを選んでもよい

### 3-3. YouTube Studio で予約投稿する

1. ［作成］→［動画をアップロード］→ `<記号>_final.mp4`（作れなかった場合は zip の `.mp4`）
2. タイトル・説明：zip の `.txt` の【タイトル】【説明】をそのまま貼る
3. サムネイル：あなたの `<記号>_thumb.png`（作れなかった場合は zip の `.png`）
4. 再生リスト：動画ごとの指定（無ければ作る）
5. 視聴者：動画ごとの「子ども向け」の指定
6. ［すべて表示］→ AI の使用：**はい**／タグ：`.txt` の【タグ】／動画の言語：英語／カテゴリ：音楽
7. 終了画面（子ども向け「いいえ」の動画だけ。子ども向けの動画には付けられません）：
   最後の 20 秒に「動画：視聴者に最適な動画」「再生リスト」「チャンネル登録」
8. ［次へ］×3 →［スケジュールを設定］→ 指定の日時（日本時間）→［スケジュールを設定］

### 3-4. 多言語のタイトルと説明を付ける

予約が終わったら、左メニュー［言語］→ その動画 →［言語を追加］で、動画ごとの指示にある 6 か国語
（日本語・スペイン語・ポルトガル語・ドイツ語・フランス語・韓国語）を 1 つずつ追加し、
「タイトルと説明」に貼って［公開］します。その言語で YouTube を使う人には、その言語で表示されます。
