### 11/12(木) 9:00　n09_ode_to_joy_lullaby

- zip：`n09_ode_to_joy_lullaby.zip`
- 子ども向け：**はい**　／　再生リスト：Lullabies for Babies
- 英語タイトル（`.txt` と同じ）：Ode to Joy ✨ 1 Hour Music Box Lullaby for Babies & Sleep
- 絵の指定：
```
音楽：ベートーヴェン「よろこびの歌」を、オルゴールでゆっくり。明るく澄んだ旋律。
背景：夜の子ども部屋の窓辺。右側のテーブルに、ふたの開いた木のオルゴールがやわらかく光っている。
      窓の外に星。ばら色と金色。
サムネイルの文字：
  タイトル 2 行：ODE TO / JOY
  副題：MUSIC BOX LULLABY
  バッジ：1 HOUR
```
- 多言語のタイトルと説明：

  **日本語（ja）**
  タイトル：
```
よろこびの歌 🌙 赤ちゃんが眠る子守唄 1時間｜やさしいピアノ
```
  説明：
```
「よろこびの歌」を、やさしいピアノでゆっくり1時間。調もテンポも最後まで同じで、急に大きな音は鳴りません。寝かしつけ・お昼寝・静かな夜に。

雑音（雨・波など）は入れていません。基準ピッチは A=432Hz（響きの好みによる調律で、健康効果はうたいません）。旋律はすべてパブリックドメイン、編曲と演奏はこのチャンネルのオリジナルです。
```

  **スペイン語（es）**
  タイトル：
```
Himno de la alegría 🌙 1 Hora de Canción de Cuna para Bebés | Piano Suave
```
  説明：
```
«Himno de la alegría» tocada despacio en un piano suave durante una hora. La misma tonalidad y el mismo tempo de principio a fin, sin sonidos repentinos. Para la hora de dormir y la siesta.

Sin ruido de fondo. Afinado en La = 432 Hz (una elección de afinación; sin afirmaciones de salud). Melodías de dominio público; arreglo y sonido hechos para este canal.
```

  タイトル：
```

```
  説明：
```
“Ode à Alegria” tocada devagar em um piano suave por uma hora. O mesmo tom e o mesmo ritmo do começo ao fim, sem sons repentinos. Para a hora de dormir e a soneca.

Sem ruído de fundo. Afinado em Lá = 432 Hz (uma escolha de afinação; sem alegações de saúde). Melodias de domínio público; arranjo e som feitos para este canal.
```
