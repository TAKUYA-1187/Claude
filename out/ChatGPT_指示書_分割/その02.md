```
音楽：ブラームスの子守唄。ゆっくりした 3 拍子でゆりかごのように揺れる、やわらかいピアノだけの 1 時間。
      あたたかく、少し懐かしい。
背景：夜の子ども部屋。右側に木のゆりかごと、やわらかい毛布。アーチ型の窓の向こうに三日月と少しの星。
      ランプの琥珀色の光と、窓の外の紺色。ゆりかごの曲線を主役に。
サムネイルの文字：
  タイトル 2 行：BRAHMS' / LULLABY
  副題：SOFT PIANO FOR BABIES
  バッジ：1 HOUR
```

  **日本語（ja）**
  タイトル：
```
ブラームスの子守唄 🌙 赤ちゃんが眠る子守唄 1時間｜やさしいピアノ
```
  説明：
```
「ブラームスの子守唄」を、やさしいピアノでゆっくり1時間。調もテンポも最後まで同じで、急に大きな音は鳴りません。寝かしつけ・お昼寝・静かな夜に。

雑音（雨・波など）は入れていません。基準ピッチは A=432Hz（響きの好みによる調律で、健康効果はうたいません）。旋律はすべてパブリックドメイン、編曲と演奏はこのチャンネルのオリジナルです。
```

  タイトル：
```

```

```

Sin ruido de fondo. Afinado en La = 432 Hz (una elección de afinación; sin afirmaciones de salud). Melodías de dominio público; arreglo y sonido hechos para este canal.
```
