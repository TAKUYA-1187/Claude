# ChatGPT に共有するメッセージ（絵の作成 → アップロード）

2026-10-31 作成（Claude）。

## オーナーがすること

1. ChatGPT で新しいチャットを開く（YouTube Studio を操作できるエージェント機能があれば、それを使う）
2. 次の3つのファイルを添付する
   - `GPT_アップロード指示書.md`（公開日時・子ども向けの設定の表）
   - `ChatGPT_絵とサムネの依頼文.md`（動画ごとの絵の指定）
   - この文書（`ChatGPT_共有メッセージ.md`）
3. 下の「■ ここから ChatGPT へ」から最後までを貼って送る
4. 動画の zip は、ChatGPT が「次は○○の zip をください」と言ったときに、その分だけ添付する
   （1つ 220〜400MB なので、まとめて添付すると失敗しやすい）
5. 第2段階の背景画像が届いたら、Claude のチャットに添付する（Claude が動画を作り直して返します）

---

## ■ ここから ChatGPT へ

YouTube チャンネル「Quiet Hours Music」の投稿を手伝ってください。音楽と動画は Claude が作りました。
あなたにお願いしたいのは、(1) 動画に合うサムネイル（と一部は背景）の絵を作ること、
(2) YouTube Studio への予約投稿 の2つです。添付の2つの文書を最初に全部読んでください。

### 大事な前提

- **動画の背景は、動画ファイルの中に焼き込まれています。** YouTube では、上げた後に動画ファイルだけを差し替えられません。
  そのため、あなたが作った背景を動画に入れたい場合は、**アップロードの前に** オーナー経由で Claude に背景画像を渡し、
  Claude が動画を作り直します。サムネイルは YouTube 上でいつでも差し替えられるので、そのまま使えます。
- すべての動画には、Claude が作った背景とサムネイルがすでに入っています。あなたの絵は、それをより良くするためのものです。

### 第1段階：11月26日までに公開する動画（今すぐ）

対象：`GPT_アップロード指示書.md` の表のうち、公開日が 11/2〜11/26 の動画（子守唄、x01・x03・x02）

1. 1本ずつ、`ChatGPT_絵とサムネの依頼文.md` の【1】の決まりと、その動画の「▼」の指定で **サムネイルだけ** を作る
   - 文字は指定どおり、スペルを1文字ずつ確認する。違っていたら作り直す
   - 11/5・11/16・11/22・11/25 のオルゴール版（n01〜n04 の _musicbox）は、【3】の指定で作る
2. オーナーに「次は○○の zip をください」と頼み、受け取った zip の `.mp4` をアップロードする
3. サムネイルは **あなたが作った画像** を使う（zip の中の `.png` は使わない。作れなかったときだけ使う）
4. タイトル・説明・タグは zip の中の `.txt` のまま。それ以外は `GPT_アップロード指示書.md` の「必ず守ること」「1本ごとの手順」のとおり
   - AI の使用：必ず「はい」
   - 子ども向け：子守唄は「はい」、クリスマスは「いいえ」
   - 長尺は1日1本まで、表の日時で予約
5. 1本終わるごとに「公開日時・タイトル・子ども向けの設定・使ったサムネイル」を報告する

### 第2段階：11月27日以降に公開する動画（背景も作る）

対象：x04〜x09（クリスマス）、w01〜w05（冬）。公開まで時間があるので、背景からきちんと作ります。

1. 1本ずつ、【2】【4】の指定で **背景（文字なし・1920x1080）とサムネイル（文字入り）の2枚** を作る
   - ファイル名：背景は `<記号>.png`、サムネイルは `<記号>_thumb.png`
2. できた2枚をオーナーに渡し、「Claude に渡してください」と伝える
   **（この段階では、まだアップロードしない）**
3. Claude が背景を動画に入れて作り直した新しい zip が届いたら、第1段階と同じ手順で予約投稿する
   （サムネイルは新しい zip の中の `.png` を使う。中身はあなたのサムネイルです）
4. 11月20日までに新しい zip が届かなかった動画は、今の zip のまま、あなたのサムネイルで予約投稿する

### Shorts

`kids_shorts_10.zip`・`christmas_shorts_12.zip`・`winter_shorts_6.zip` の Shorts は、絵の作り直しは不要です。
`GPT_アップロード指示書.md` の Shorts の表の日時で、各 `.txt` の設定どおりに予約投稿してください。

### やってはいけないこと

- AI の使用を「いいえ」にする
- タイトル・説明を書き換える（特に「眠れる」「治る」など健康効果をうたう言葉を足す）
- 同じ動画を二重に上げる、1日に長尺を2本以上公開する
- 表に無い日（11/4・11/11・12/11）に動画を上げる（Claude がまだ作っていない BGM の枠です）

### 終わったら

予約した全動画の一覧（公開日時・タイトル・子ども向け・サムネイルの作者）を表で返してください。
