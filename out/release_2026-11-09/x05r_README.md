# x05r_jingle_bells_piano（Jingle Bells の作り直し）：試作 v1

作成：2026-11-09（Claude）。GPT の指示書 §17.3 への回答です。
旧 x05（Mpl70FC93HQ）は非公開のままにしてあります。x05r は旧版の差し替えではなく、新しい制作物です。

**曲の作り**
- 4/4 拍子、♩=76、変ロ長調（出典のト長調から +3 半音）
- 構成は 20 小節：前奏 2（伴奏だけ）→ ヴァース 8（Dashing through the snow）→ サビ 8（Jingle bells）→ 終わり 2（サビの頭の音を静かに。E♭m6 の和音で冬らしく）
- 最後の 2 小節は少しずつ遅くして、響きを残して終わる
- 楽器はピアノだけです。鈴・打楽器・効果音・歌声は入れていません
- 基準ピッチは A=440 Hz。修正後のサンプル（44.1 kHz で保存）を、楽器ごとに 1 回だけ再サンプリングしています。曲全体を速くして音程を合わせることはしていません

**再現**
```
PYTHONHASHSEED=0 python3 make_x05r.py      # 音声・MIDI・QA
python3 verify_x05r.py --out <フォルダ>    # 旋律の出典との一致、旧版の和音との違い、出典ファイルの sha256
```

## 2. 出典（旋律）

**使ったもの**：『The Most Popular Home Songs』の p.54–55「Jingle, Bells」
- 出版：New York: Hinds, Hayden & Eldredge, 1913
- 編曲：George Rosey。「Copyright, 1908, by Hinds, Noble & Eldredge」と印刷あり
- 画像：Internet Archive `mostpopularhomes00nobl`（leaf 61 = p.54、leaf 62 = p.55）。2026-11-09 に取得し、`data/licenses/x05r_jingle_bells/1913_most_popular_home_songs/` に保存
- 使った部分：声楽譜の上声（旋律）だけ。Rosey のピアノ伴奏と和音は使っていません
- 読み取り：Claude が画像を拡大して、1 音ずつ読みました（`bgm_studio/xmas_r.py` の `SOURCE_1913_G`）
- 確かめた結果：x05r の旋律は、この読み取りを +3 半音移しただけで、97 音すべて高さ・長さとも一致しています（`x05r_verification.json`）

**今の一般的な旋律との違い**（この版の通りにしました）
- ヴァース 3 小節目「O'er the fields we **go**」の長い音：この版は E4（今の一般的な形は F#4）
- サビ「one-horse **o**-pen sleigh」の 4 つ目の音：この版は G4（今の一般的な形は B4）

**参考にした 1857 年の初版**
- 書誌：Boston: Oliver Ditson、plate 18200、1857-09-16
- 画像：米国議会図書館の画像を、Wikimedia Commons（Public domain の表示）で閲覧。`data/licenses/x05r_jingle_bells/1857_first_edition_loc/` に保存
- ヴァースは同じ形です（A♭長調・2/4 拍子で、音価は半分）
- ただし「Laughing all the way」の所は違います（初版は低い音から跳ね上がる形）
- **サビは今と別の旋律**です（上がっていく形で、「way」に E♮ が付く。歌詞も「Oh! what joy」）
- このため、よく知られたサビの形は初版ではなく、1908/1913 年版から取りました

**取得できなかったもの**（どちらも回避はしていません）
- IMSLP の初版 PDF：人間確認（CAPTCHA）が必要だったため
- 米国議会図書館のサイト：Cloudflare の確認画面が出たため

## 3. 編曲（和音・伴奏）は新しく作った

- 和音は Claude が新しく付けた 4 和音です（maj7・m7・sus4・6、終わりの E♭m6 など）
- 伴奏は、4 分音符でゆっくり分散させる形です
- 旧 c09（Paul Hardy 版の和音記号）との比較は、旋律の同じ音の上で比べて次のとおりです。根音だけの一致は、主和音・属和音など、どの編曲でも重なりやすい所を含みます
  - 和音名の一致：14.6%
  - 根音だけの一致：46.9%
- 1 回目の試作では、低い E♭・D の低音の上で旋律の D5・E♭5 がぶつかる所が 10 か所ありました。和音を付け直して、0 か所にしました
