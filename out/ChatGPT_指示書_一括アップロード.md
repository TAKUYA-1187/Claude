# ChatGPT への指示書：残りの全動画を仕上げて、5 分おきにアップロード（予約）する

作成：2026-11-01（Claude）。
「ChatGPT_指示書_完全版.md」と「ChatGPT_指示書_追加_人気ジャンル6本.md」の内容をまとめ直し、
**作業の進め方をこの文書で上書き**します。動画ごとの絵の指定と多言語のタイトル・説明は、その 2 つの文書のものを使います。

## 0. オーナーへ（この部分は ChatGPT に貼らなくてよい）

### 0-1. 添付するファイルの確認（大事）

Finder の一覧で「種類：URL」「サイズ：1 KB」になっている `zipn13_…`・`zipn14_…`・`zipn15_…` などは、
**動画ではなく「リンク（ショートカット）」**です。ChatGPT に渡しても中身がなく、「素材待ち」のままになります。

1. ChatGPT の入力欄に並んでいる `zipn…` で始まるファイルは、右上の × で外す
2. Claude のチャットから届いた zip（`n13_rockabye_baby.zip` など、`zip` が名前の前に付いていないもの）を
   ダウンロードする。Finder で「種類：ZIP アーカイブ」「サイズ：40〜400 MB」になっていれば本物
3. その本物の zip を ChatGPT に添付する

### 0-2. ChatGPT に送るもの

1. 今の ChatGPT のチャット（「子供向け動画制作 Upload」）に、次の 3 つの文書を添付する
   - `ChatGPT_指示書_一括アップロード.md`（この文書）
   - `ChatGPT_指示書_完全版.md`
   - `ChatGPT_指示書_追加_人気ジャンル6本.md`
2. 次の 1 行を送る：
   「一括アップロードの指示書を最初から読み、それに従って作業してください。動画ごとの絵と多言語は、残りの 2 つの文書を使ってください。」
3. ChatGPT に「○○.zip をください」と言われたら、本物の zip を添付する（一度に 5 つまでが安定します）

### 0-3. 「5 分おき」について（Claude からの説明）

ご指示どおり、**アップロードは 5 分おき**に行います。ただし**公開日時は、これまでの予定表どおり 1 日 1 本**
（子ども向けの朝 9:00 と、大人向けの昼 12:00／夜 21:00 が同じ日に重なる日もあります）のまま、「予約」で上げます。

理由：長い動画を短い間隔で次々に**公開**すると、
- 登録者への通知が一度に何十本も届き、1 本ずつの最初の再生数（おすすめに載るかを決める数字）が分散する
- 同じような長い音楽動画の大量公開は、YouTube の「繰り返しの多いコンテンツ」の確認にかかりやすく、収益化の審査に不利

アップロード作業そのものは 5 分おきで一気に終わらせ、公開は毎日 1 本ずつ自動で行われます。
すぐに全部を公開したい場合は、Claude にそう伝えてください（おすすめはしません）。

### 0-4. x03・x05 の「著作権の申し立て」について

ChatGPT から「x03・x05 に著作権の申し立てがある」と報告がありました。
旋律はどちらも 100 年以上前のもの（パブリックドメイン）で、演奏と録音はこのチャンネルで作ったものなので、
**誤った申し立て**の可能性が高いです。ただし、異議申し立ては**チャンネルの持ち主の名前で出す法的な手続き**なので、
ChatGPT には出させません。ChatGPT が下の「7.」で集める情報（申し立てた会社、該当する時間など）を、Claude に送ってください。
内容を見て、異議申し立ての文面と手順をお渡しします。

## 1. ChatGPT へ：あなたの役割

YouTube チャンネル「Quiet Hours Music」（録音した楽器による、静かな音楽の長い動画）の動画を仕上げて、
YouTube Studio に **5 分おきに 1 本ずつアップロードし、決められた日時に公開されるよう予約**してください。
目標は、国内外の人に「クリックされ（高い視聴数）」「最後まで、何度も聞かれる（高いリピート）」動画にすることです。

音楽と動画（mp4）は Claude が作り、音量・雑音・無音の検査に合格しています。あなたの担当は次の 5 つです。

1. **絵**：動画ごとに、背景（文字なし）とサムネイル（文字入り、3 案）を作る
2. **動画**：あなたの背景をゆっくり動かした映像と、Claude の音声を組み合わせて、最終の動画を作る
3. **アップロードと予約**：5 分おきに 1 本、下の予定表の日時で予約する
4. **見続けてもらう設定**：再生リスト・終了画面・チャプター・サムネイルのテスト
5. **多言語化**：6 か国語のタイトルと説明を追加する

## 2. 必ず守ること

- アップロードは **5 分おきに 1 本**。公開は「予約」にし、**下の「5. 予定表」の日時（日本時間）以外に公開しない**
- 「改変されたコンテンツ／AI の使用」は **すべて「はい」**
- 「子ども向け」は予定表どおり（子守唄は「はい」、それ以外はすべて「いいえ」）
- タイトル・説明・タグは zip の中の `.txt`（英語）を **そのまま** 使う。
  「眠れる」「治る」「不安が消える」「脳に効く」など、健康の効果をうたう言葉を足さない
- **音声は加工しない**（音量・音質は検査済み。下の 4-3 で、元と同じかを必ず確かめる）
- 同じ動画を二重に上げない。すでにアップロード・予約した動画は飛ばす（最初に YouTube Studio の［コンテンツ］で確認する）
- 実在の作品・キャラクター・ブランド・画家に似せた絵を作らない。人の顔は描かない
- 本物の楽器ではないものを本物と言わない（h01 はヴィブラフォンで作った「Handpan-Style」、f01 はアルトフルート）
- 受け取った zip が 1 MB より小さい、または開けないときは、作業せずオーナーに「本物の zip をください」と伝える
- 著作権の申し立てに、あなたの判断で「異議申し立て」も「承諾」もしない（7. を見る）

## 3. 絵：背景とサムネイル

### 3-1. 共通のルール

「ChatGPT_指示書_完全版.md」の **3-1 の共通のルール**（画風、文字の書体と色、配置、音楽と絵の合わせ方）に従います。
そのうえで、視聴数とリピートを上げるために、次を必ず守ってください。

**サムネイル（クリックされるため）**
- スマホの一覧（横 160px）で 1 秒見て「何の音楽か」がわかる。主役は 1 つだけ、大きく、右側に
- 文字は英語で 2〜4 語まで（指定どおり）。文字と背景の明るさの差を大きくする（暗い背景にクリーム色の文字）
- 同じシリーズ（子守唄・クリスマス・冬・クラシック・瞑想・ジャズ）は、構図と色の決まりを同じにして、
  一覧で並んだときに「同じチャンネルのシリーズ」とわかるようにする
- **1 本につき 3 案**作る（主役・色・構図を変える。文字は同じ）。ファイル名 `<記号>_thumb_a.png`・`_b.png`・`_c.png`
- 3 案の中で、あなたがいちばんクリックされると思うものを `_a` にする

**背景（最後まで見てもらうため）**
- 1〜2 時間ずっと映るので、目が疲れない明るさとコントラストにする。白い部分を広くしない
- 画面の左 1/3 は空・水面・遠景など静かな部分にする（動かしたときに落ち着いて見える）
- 細かい模様・細い線・文字・ロゴは入れない
- サムネイルと同じ場面・同じ色にする（クリックした人が「この絵の動画だ」と安心して見続けるため）

### 3-2. 動画ごとの絵の指定

- 子守唄・クリスマス・冬：「ChatGPT_指示書_完全版.md」の「4. 動画ごとの指示」の「絵の指定」
- h01・k01・k02・k03・f01・j01：「ChatGPT_指示書_追加_人気ジャンル6本.md」の「2. 動画ごとの指示」の「絵の指定」
- 「絵：そのまま」とある動画は、すでにあなたの絵が入っているので作らない（サムネイルの 3 案だけ作る）

## 4. 動画を作る

### 4-1. 背景をゆっくり動かす映像（おすすめ）

背景の絵を 30 秒かけてごくわずかに寄って戻る映像にし、それをくり返します。止まった絵より、見ている人が離れにくくなります。
```
# 30 秒の映像（最初と最後が同じ大きさなので、つなぎ目が見えない）
ffmpeg -loop 1 -i <記号>.png -vf "scale=3840:2160:force_original_aspect_ratio=increase,crop=3840:2160,zoompan=z='1.0+0.03*(1-cos(2*PI*on/720))/2':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=1:s=1920x1080:fps=24,format=yuv420p" \
  -frames:v 720 -c:v libx264 -preset slow -crf 18 -g 48 loop30.mp4

# 音声は Claude の動画からそのまま取り出す
ffmpeg -i <記号>.mp4 -vn -c:a copy audio.m4a

# 30 秒の映像を音声の長さまでくり返して、音声と合わせる（映像も音声も再圧縮しない）
ffmpeg -stream_loop -1 -i loop30.mp4 -i audio.m4a -map 0:v -map 1:a -c copy -shortest -movflags +faststart <記号>_final.mp4
```

### 4-2. うまくいかないとき

- 上の方法で止まる・遅すぎるときは、「ChatGPT_指示書_完全版.md」の 3-2 の方法（止まった絵）で作る
- それも無理なときは、zip の `.mp4`（Claude が作った、光や雪がゆっくり動く映像）をそのまま使い、背景画像はオーナーに渡して
  「Claude に渡してください」と伝える

### 4-3. できた動画の確認（必ず）

```
ffprobe -v error -show_entries format=duration -of csv=p=0 <記号>.mp4
ffprobe -v error -show_entries format=duration -of csv=p=0 <記号>_final.mp4
ffmpeg -v error -i <記号>.mp4 -map 0:a -c copy -f md5 -
ffmpeg -v error -i <記号>_final.mp4 -map 0:a -c copy -f md5 -
```
- 長さの差が 1 秒以内
- 音声の md5 の 2 つの値が **同じ**（音声が加工されていない証拠）。違ったら作り直す
- 最初・まん中・最後の 3 か所の画面を書き出して、絵が崩れていない・黒い画面がないことを見る

## 5. アップロードと予約（5 分おき）

### 5-1. 進め方

1. YouTube Studio の［コンテンツ］で、すでにアップロード済みの動画を確認し、下の予定表から外す
2. 予定表の **公開日の早い順** に、1 本ずつ次の 5-2 を行う
3. 1 本の［スケジュールを設定］を押した時刻から **5 分後に、次の 1 本のアップロードを始める**
   （YouTube の処理（HD 化）が終わるのを待たなくてよい）
4. 「1 日にアップロードできる本数の上限に達しました」と出たら、その日はそこで止め、オーナーに伝えて翌日に続ける

### 5-2. 1 本の手順

1. ［作成］→［動画をアップロード］→ `<記号>_final.mp4`
2. タイトル・説明：`.txt` の【タイトル】【説明】をそのまま貼る（説明の `00:00 …` の目次は消さない。チャプターになる）
3. サムネイル：`<記号>_thumb_a.png`
4. 再生リスト：予定表の再生リスト（無ければ作る。名前は予定表どおり）
5. 視聴者：予定表の「子ども向け」
6. ［すべて表示］→ 改変されたコンテンツ（AI の使用）：**はい**／タグ：`.txt` の【タグ】／動画の言語：英語／カテゴリ：音楽
7. ［次へ］→ 動画の要素：
   - 子ども向け「いいえ」の動画だけ：終了画面を付ける（最後の 20 秒に「動画：視聴者に最適な動画」「再生リスト（同じシリーズ）」「チャンネル登録」）
   - 子ども向け「はい」の動画は、終了画面・カードを付けられないので何もしない
8. ［次へ］→［公開設定］→［スケジュールを設定］→ 予定表の日時（日本時間）→［スケジュールを設定］
9. 予約が終わったら：
   - **サムネイルのテスト**：その動画の［詳細］→ サムネイルの［テストと比較］が使えるときは、`_a`・`_b`・`_c` の 3 案を登録する
     （使えない動画は `_a` のまま）
   - **多言語**：左メニュー［言語］→ その動画 →［言語を追加］で、6 か国語（日本語・スペイン語・ポルトガル語・ドイツ語・フランス語・韓国語）の
     タイトルと説明を、動画ごとの指示から貼って［公開］
   - 多言語の作業は、5 分の待ち時間の間に行ってよい

## 7. 著作権の申し立てがあったとき（x03・x05 を含む）

1. YouTube Studio の［コンテンツ］→ その動画の［制限事項］→「著作権侵害の申し立て」→［詳細を表示］
