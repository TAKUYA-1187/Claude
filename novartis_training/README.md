## 設計の要点

**戦略的思考 ＝ ①影響力（誰が、何を動かせるか）× ②影響の輪（どこまで届くか）**

- **到達目標は公式文言を維持**し、その下に「本日の到達点：誰が何を動かせるかを整理し、次に確認する情報と行動を決められる」を併記（二段構え）
- **疾患・製品の戦略は作らせない**。IgA腎症は本編の主語にせず、「C3腎症の経験や今後のIgA腎症をイメージしてもOK」の補足と、まとめの接続一文のみ
- チェックインは1問：「この3回で、実際に変わったことは何ですか？」→ Teamsチャットに1行
- ワーク①は4STEP（2/3/2/1分）＋完成条件「最も影響力が大きいと考えるのは〇〇施設の△△先生。□□を動かせるから」
- 共有①は時計回り・1人60秒・発表の型あり。質問は「その判断の根拠になった情報は何ですか？」（DAY3接続）
- レクチャー②の本質＝目的からの逆算：実現したい状態→期待する役割→分からないこと→取りに行く情報→次の行動
- ワーク②は Q1目指したい状態／Q2使いたい影響力／**Q3実現したいこと（分からなければ確認事項の二択）**／Q4次の一手。完成文4行が最終成果物
- ディスカッションは1人3分×3人＋気づき3分。質問は「その情報が分かると、次の活動はどう変わりますか？」
- まとめは3点（誰が動かせるか／どこまで届くか／何を確認するか）＋「影響力の仮説と確認リストが、そのままIgA腎症の準備になる」の一文
- 冒頭1〜7枚は当日投影を3枚（タイトル／ロードマップ／Agenda）に絞る運用を進行メモに明記
