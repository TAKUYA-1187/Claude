## 設計の要点

**本日の到達点：自分のエリアにおける影響力のつながりを、自分の言葉で説明できる**
（公式の到達目標「収集した情報から、エリアの課題・原因・解決方法を可視化できる」は文言のまま併記）

- チェックインは「この3回で、あなたの**『大学の見方』**は変わりましたか？　大学担当としての
  **『自信』**はつきましたか？」の1問。Teamsチャットへ自由に書き込む形で、
  「大学に行くとき、以前と違うことは？」「会う人・聞くことは、変わった？」「まだ『分からない』と思うことは？」
  の3つの切り口を添えた
- **テーマ①＝過去の経験の共有**。「この先生・この施設が鍵だった」と気づいた経験を持ち寄る。
  3〜4人で自由に話し、最後にグループで「見極めるうえで重要だったこと」を1つ決める
- 全体共有①で、出てきた経験を **①周囲の反応／②実際の役割／③届く範囲** の3つの見方に整理。
  「肩書きではなく、周囲の反応・実際の役割・届く範囲で見る」に着地
- **テーマ②＝藤さんの事例（10分）を先に見せてから、自分のエリアに当てはめる**。
  事例は成功事例紹介ではなく「どの情報から、エリア内の影響力のつながりを読み取ったか」を見せる回。
  スライド18–21は藤さん記入用のテンプレート（①背景1分／②転機2分／③つながり3分／④変化と学び4分）
- 個人ワークは「正確な組織図は不要」と明示。文字でも図でも可、分からない関係は「？」のままでよい
- ディスカッション②は3人1組。最後に「他の人のエリアと最も違っていた点」を話す
- 全体共有②は **「エリアの見方は、どう変わったか」**
- 行動宣言は Teams チャットに「自分のエリアで、次に確かめたいこと」
- **疾患・製品の戦略は作らせない**。IgA腎症・C3腎症は付録Hの参考例のみ
- 詳細な講義コンテンツ（影響力の見極め方、エリアパターン、情報源、肩書き、コンプライアンス）は
  すべて付録に格納し、本編は問いと対話に集中させた。本編のレクチャーは合計6分
