# Renal 大学/基幹病院担当者スキルアッププロジェクト DAY4

「ちょっと分かるだけで世界が変わる」（シリーズ最終回）

## ファイル

- `DAY4_ちょっと分かるだけで世界が変わる.pptx` — 研修資料本体（全40枚）
- `build_session4_deck.py` — 生成スクリプト（python-pptx）。文言修正後に `python3 build_session4_deck.py` で再生成できます。

## 設計の前提

- **公式ゴール（戦略的活動）**：担当施設と周辺エリアに対する成功像・現状・課題・解決法を言語化できる
- **本編60分**（DAY3と同じ運用尺）＋内容により30分延長オプション
- DAY3資料の様式に準拠：DAY表記／Agenda（■＋分）／TODAY'S DESIGN／Ice Break／グループワーク／行動宣言
- 参加者62名の事前アンケート（不安・期待）に全項目対応
