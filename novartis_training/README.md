## 設計の要点

**戦略的思考 ＝ ①影響力（誰が、何を動かせるか）× ②影響の輪（どこまで届くか）**

- 到達目標は公式文言「収集した情報から、エリアの課題・原因・解決方法を可視化できる」。2つのサブ目標
  （施設情報を構造で整理しキーパーソンを特定／エリアアプローチ戦略を検討・説明できる）をテーマ①②に対応表示
- **疾患・製品の戦略は作らせない**。IgA腎症は本編の主語にせず、まとめの接続一文と付録Cのみ
- DAY3の最後の問い「営業として、その情報をどう活かすか」を今日の入口として明示
- **「その情報は、誰から取れるか」スライド**（DAY3の回収）：医師本人／周辺関係者／学会・研究会の3分類、
  聞き方のコツ（仮説を持ちクローズドで聞ける状態に）、噂は複数で確認、信頼が深まるサイン（プライベート／将来の話）
- ワーク①は4STEP（2/3/2/1分）＋完成条件の一文
- 共有①は時計回り・1人60秒・型あり。質問は「その判断の根拠になった情報は何ですか？」
- ワーク②は Q1目指したい状態／Q2使いたい影響力／Q3実現したいこと（DAY3の「成し遂げたいことを直接聞く」／
  分からなければ確認事項の二択）／Q4次の一手。完成文4行が最終成果物
- ディスカッションは1人3分×3人＋気づき3分。質問は「その情報が分かると、次の活動はどう変わりますか？」
- DAY3の共有事例（同年同卒・同門を調べて講演会を設計→参加率向上・接点創出・エリア認知向上）を逆算スライドに掲載
- DAY3のチーム展開（営業所全員で顧客理解／Tips共有）を行動宣言と最終メッセージに接続
- 冒頭1〜7枚は当日投影を3枚（タイトル／ロードマップ／Agenda）に絞る運用を進行メモに明記
