## 中心となる考え方

**戦略的思考 ＝ ①影響力（誰が、何を動かせるか）× ②影響の輪（どこまで届くか）**

- **担当施設は大学病院（HS）と基幹病院（HP）。開業医（GP）は担当外**だが、患者の流れの起点としてエリアの絵には存在する
- テーマ①はDAY1の「"影響力"を紐解いてみよう」を、自分の担当施設で実際にやる回。DAY2で会えた人・DAY3で分かったニーズをここで結びつける
- 影響力は「肩書き」ではなく「何を動かせるか」（教育／研究／臨床／医局人事／医師派遣／情報発信／講演会）で見る
- 影響力は1人に集中しない：◎方針を決める人／○最初に試す人／★情報ハブ／◇連携の要／□対外の顔
- テーマ②は影響の輪（施設の中→関連病院→担当エリア→営業所・その先）をエリアプランニングへ広げる回
- 大学に固執しない。大学はエリアの中の1施設。輪が一番大きいのは大学とは限らない
- 輪を動かすには相手のWINが要る。エリアで実現したいことと医局がしたいことの重なりに打ち手を置く
- エリアプランニングは5ステップ：①成功像 →②輪を選ぶ →③WINを重ねる →④情報を取る（DAY3）→⑤やって、直す
- ワークは「丸を描く」「3つの問い」だけ。答えが出なくても「分からない」と気づけたら収穫
- 共有・ディスカッションは型にはめず、テーマを示してフリーに話してもらう
- Beyondは「プラス1」。全員必達にしない
