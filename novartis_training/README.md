## 設計の要点

**戦略的思考 ＝ ①影響力（誰が、何を動かせるか）× ②影響の輪（どこまで届くか）**

- チェックインは**1問のみ**：「この3回で、実際に変わったことは何ですか？」→ Teamsチャットへ1行。例3つ＋不安でも可
- ワーク①の冒頭で**対象疾患を1つ選ばせる**（慢性糸球体腎炎の診療／IgA腎症など）。疾患が違えば重要施設もキーパーソンも変わる
- ワーク①は**完成条件を明示**：「この疾患で最も影響力が大きいのは〇〇施設の△△先生。□□を動かせるから」
- 共有①は**時計回り・1人60秒・発表の型あり**。聞き手の質問は「その判断の根拠は何ですか？」の1つ
- ワーク②は到達目標と一致：**Q1成功像／Q2使う影響力／Q3相手のWIN／Q4次の一手**。完成文4行が最終成果物
- ディスカッションは**1人3分（発表2分＋質問1分）×3人＋気づき1分**。質問は「その打ち手で、成功像に本当に近づきますか？」
- 終盤5分は**まとめ（3点）→ 行動宣言 → 最終メッセージ**の3枚に整理
- 本編からGP（開業医）の説明は削除。ワークシート注記に「その他の医療機関は背景となる患者動線として必要に応じて記載」と記す
- 冒頭1〜7枚は当日投影を3枚（タイトル／ロードマップ／Agenda）に絞る運用を進行メモに明記
