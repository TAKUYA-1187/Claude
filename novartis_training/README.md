## 中心となる考え方

**戦略的思考 ＝ ①どこを見るか（視座）× ②何のために動くか（順序）**

- **担当施設は大学病院（HS）と基幹病院（HP）。開業医（GP）は担当外**だが、患者の流れの起点として範囲の絵には存在する
- DAY4は知識を「増やす」回ではなく「使う」回
- DAY1で考えた「先生のテリトリー」を、「自分のテリトリー」に置き換える
- 大学の攻略 ≠ 任された範囲の攻略。大学の枠を外し、範囲全体の中に大学を置き直す
- 大学の機能（教育／研究／臨床／医局人事／医師派遣／情報発信／講演会）から、目的に合うものを選ぶ
- 情報は成功像と仮説から逆算して取りに行く（DAY3の「取り方」に「取りに行く理由」を足す）
- 大学に固執しない。大学は「エリアマッピングの中の1施設」。その影響力を誰に・何を・どこまで効かせるかを設計する
- 打ち手は「自分の範囲の成功像」と「大学・医局がしたいこと」が重なるWIN-WINの位置に置く
- 言語化の形式は自由。整った戦略より「なぜ重要か」を語れること（4Sは付録の一例）
- 後半のBeyondは「プラス1」。全員必達にしない
- ワークの共有は型にはめず、テーマを示してフリーにディスカッションしてもらう
- ワークは「丸を描く」「3つの問いに答える」だけ。答えが出なくても、分からないと気づけたら収穫
