## 中心となる考え方

- 第4回は知識を「増やす」回ではなく「使う」回
- 大学の攻略 ≠ 任された範囲の攻略。大学という枠を外し、範囲全体の中に大学を置き直す
- 大学の機能（診療／研究／教育／医局人事／医師派遣／情報発信／講演会・研究会）から、目的に合うものを選ぶ
- 情報は目的と仮説から逆算して取りに行く
- 「要望に応える活動」から「範囲の課題から大学を動かす活動」へ
- 4Sは目的ではなく手段。整ったシートより「なぜ重要か」を語れること
- 後半はBeyond（プラス1）。全員必達にはしない
