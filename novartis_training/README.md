## 設計の柱

**一本道：Fact → 仕分け → 仮説 → 4S／エリアプラン**

- **ニーズ＝理想と現状のGap（状態）／ウォンツ＝Gapを埋める具体的な手段**（ROTF3 顧客理解・意思決定能力）。
  顕在ニーズ・潜在ニーズもここで扱う
- 情報を **Fact（事実）／ウォンツ（手段）／ニーズ（状態）** の3つに分ける形にしたため、
  DAY3で集めた情報がそのまま教材になる。判定の目安は「これは状態か、手段か」「願望が入っていなければFact」
- **ワーク①の題材は腎臓内科の医局から得た情報9件**（製品には紐づけない）。
  Fact／ウォンツ／ニーズが3つずつになる設計で、答え合わせは付録A
- **ワーク②**は自分の担当施設の情報で、ウォンツに「なぜ？」を重ねてニーズへ降り、仮説を1文にする。
  仮説の型は1行のみ（「〇〇（Fact）から、この医局は〇〇（ニーズ）を満たしたいのではないか」）
- **4Sとの対応を明示**：ニーズ→成功像／Fact→現状／仮説→課題・原因／ウォンツ→解決策の入口。
  「4Sは埋める表ではなく、仕分けと仮説ができていれば自然に埋まる」
- **Triple Win（患者・顧客・自社）を Beyond（関連病院・近隣大学・地域の先生）まで広げる**。
  大学を「個」で見るか「エリアの1施設」として見るかで打ち手が変わることを対比で示す
- **まとめは女子医大の活動**。初回面談の一言「女子医大腎臓内科を全国に売り出したい」＝ウォンツ →
  その裏の「実臨床の経験を全国と地域に届ける場がない」＝ニーズ → 「女子医大をHUBにすれば横展開が起こる」＝仮説 →
  3大学＋院内（小児腎・移植）を企画段階から巻き込む設計 → 参加35名・処方確約1例・患者発掘1例・IC向上2施設・
  医師同士の関係性を複数確認。大学を個で見ず、エリアの1施設として影響の輪を設計した事例として提示
- ⑨総括は所長用の記入エリアを確保
