## 設計の柱

**一本道：Fact → 仕分け → 仮説 → 4S → 解決策**

ワーク①の例題（13枚目）からワーク②の4S（21枚目）まで、**A病院という一つの実在施設の素材で貫通**している。
13で仕分け → 17で出典を明かす → 18で整理 → 19で3つの仮説 → 20-21で自分の施設へ → 22でA病院の4S。

- **Needs＝理想と現状のGap（状態）／Wants＝Gapを埋める具体的な手段**（ROTF3）。
  判定の目安は「これは状態か、手段か」「願望が入っていなければFact」
- **ワーク①（10分）は2部構成**
  - 前半4分：例題9件を3つに仕分ける。**9件はすべてA病院の公開情報から作った実素材**
    （腎生検数の推移／血液浄化センター・臨床研究・学会発表のページ／部長の前任地での立ち上げ経験／
    広報誌の言葉5つ）。13枚目の記入欄に番号を入れる。答え合わせは付録A（Fact 4件／Wants 2件／Needs 3件）
  - 後半6分：「先生のWantsから、Needsを汲み取れた経験は？」を3〜4人で共有。
    15枚目の記録シートの1行目には、医師との面談で汲み取った内容を記入例として入れてある
    （基幹病院 腎臓内科部長との面談：「もっと早い段階で腎生検をして、診断をつけて治療に入りたいんだよね」→
    早期に生検・診断まで持っていける患者が、限られている → 資料を渡すのをやめ、
    「腎生検のタイミング」の症例検討会を企画）。Needs欄は「〜が限られている」＝満たされていない状態の形で書き、
    列の副題を「なぜ、そう言ったのか（＝そのときの仮説）」、下の帯を「Needsは仮説です。ここで書いた読み方が、
    唯一の正解とは限りません」として、19枚目の「仮説は複数立つ」と矛盾しないようにしてある。
    A病院の事例はこの後（17枚目〜）に出るため参照しない
  - 付録Aの学び：**公開情報から取れたWantsは、わずか2件。Wantsは、面談でしか増えない**。
    これが14枚目（面談の経験を共有する）への橋渡しになる
  - 直後に付録B・Cを投影し、ワーク②の材料にする
- **A病院の事例（17〜19・22枚目）** — 実在する基幹病院の公開情報にもとづく通し教材
  - **17枚目｜根拠**：見出しは「先ほどの9件は、すべてこの2つから取れます」。
    病院ホームページ「実績」ページの表と、開業医向け広報誌の着任あいさつを出典つきで引用
    （URL・施設名・氏名は伏せ字、年度は相対表記）。「面会の前に、公開情報だけでここまで分かる」＝DAY3のDry情報の実物
  - **18枚目｜FactとWants**（見出し「仕分けたFactとWantsを、並べて見る」）：Fact①腎生検数の推移（28→36→**90**→96→99。着任年に2.5倍、その後横ばい）、
    Fact②血液浄化センター／臨床研究／学会発表／認定施設のページを持つ・部長は前任地で腎臓内科の立ち上げと
    血液浄化センター開設を経験・診療範囲が広い・着任月に広報誌へ寄稿。
    Wantsは広報誌の言葉を3つ引用（紹介してほしい／どんな腎疾患でもベストな医療を／透析の話の前に回避策を一緒に考えたい）。
    「Wantsは3つある。どれも『やりたいこと』で、まだ『満たされていない状態』ではない」
  - **19枚目｜Needs仮説の深掘り**：同じWants「いつでもご紹介頂けますと幸いです」から3つの仮説を並列に立てる。
    各列は Needs（状態）→ 確かめる質問 → この仮説なら解決策は、の3段
    - **仮説A 早期に生検・診断まで持っていきたい**（臨床の目線）：早期に生検・診断まで持っていける患者が限られている →
      「どの段階でご紹介いただけると、生検まで持っていけますか？」→ 「腎生検のタイミング」をテーマに、先生を演者にした症例検討会
    - **仮説B 透析を減らして評価されたい**：透析を回避した成果を院内外に示す場がない →
      「腎生検が増えて、次に変わってほしいことは？」→ 保存期CKDの症例検討会を、〇〇先生を中心に設計
    - **仮説C 前任地の体制を再現したい**：立ち上げた体制と実績がまだない →
      「前任地で再現したい仕組みは？」→ 近隣の基幹病院・大学の腎臓内科医とつなぎ、再現の土台をつくる
    - 締め「打ち手はすべて、〇〇先生に対して。開業医は、その先にいる」
  - **22枚目｜4S**：「A病院の〇〇先生に対して、何ができるか」。仮説A（早期に生検・診断まで持っていきたい）を
    選んで4Sに落とす。成功像は「早期に生検・診断がつき、治療介入で透析に至る患者さんが減っている」、
    原因は「院内の生検体制は整ったが、早期に紹介される患者がまだ限られている」。
    ノバルティスができること／患者WIN・〇〇先生WIN・自社WINまで設計する。
    締めは「担当は大学・基幹病院。その先生のやりたいことを、エリアで実現できる形にする」

  **視点**：参加者は大学・基幹病院の担当で開業医は担当しないため、MRの打ち手はすべて
  「A病院の〇〇先生に対して」の形にしてある。開業医は、〇〇先生が発信する先＝成果が届く相手として置く
- **ワーク②（10分）は 仮説 → 4S → 解決策 まで**。20枚目の仮説の例・解決策の例は、
  上位3件をA病院の仮説A・B・Cに対応させてあり、事例からそのまま地続きで自分の施設に移れる。
  21枚目の4Sシートに書き切る
- **4Sとの対応**：Needs→成功像／Fact→現状・課題／仮説→原因／Wants→解決策の入口
- **Triple Win（患者・顧客・自社）を Beyond（関連病院・近隣大学・地域の先生・患者さんの流れ）まで広げる**
- **まとめは女子医大の活動**。一言のWants「女子医大腎臓内科を全国に売り出したい」→
  Needs「実臨床の経験を全国と地域に届ける場がない」→ 仮説「女子医大をHUBにすれば横展開が起こる」→
  設計と成果（参加35名／処方確約1例・患者発掘1例・IC向上2施設／医師同士の関係性を複数確認）
- 一つのWantsに複数のNeeds仮説。決めつけず、質問で確かめる

## 付録

| | 内容 |
|---|---|
| A | ワーク① 仕分けの一例（各3件。仕分けが割れること自体が確認すべき情報の在りか） |
| B | 考えられるFact 30件（施設・診療体制／患者・診療実態／人事・組織／教育・研究・学術／関係性／地域・外部環境） |
| C | Wants → 複数のNeeds仮説 → 確かめる質問（12種）。中央列はNeedsの例としても使える |
| D | 4Sへつなげる思考プロセスの参考例×3（勉強会／全国発信／腎病理教育）＋ 解決策の広がり4層 |
