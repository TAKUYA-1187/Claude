# kao_deals：お得情報の「同じ商品」を、自分の広告リンクと独自の文章で原稿にする

対象アカウント：KAO｜お得な買い物メモ（@kao_choco1187）。投稿はしない（公開は台帳担当が正規の接続で行う）。

## 使い方

```bash
pip install -r requirements.txt
export RAKUTEN_AFFILIATE_ID=あなたの楽天アフィリエイトID   # 楽天の広告リンクを作るときだけ
python kao_deals.py posts.txt --ledger kao_ledger_snapshot.json --out out/
```

`posts.txt` には、気になった投稿のURLを1行に1つ書く。結果は `out/candidates.json`（台帳担当へ渡す）と `out/drafts.md`。

## 1投稿ごとの処理

1. X 公式の埋め込み用窓口（oEmbed）で投稿の本文とリンクを読む（ログイン不要）
2. 短縮リンクと他人の広告リンクをたどって商品そのものを特定し、他人の広告ID・計測タグを捨てる
3. 停止対象（ベッドテーブル関連）と、台帳に同じ商品IDがあるかを確認する
4. 自分の広告リンクを作り、同じ商品に届くかを実際にたどって確かめる（楽天のみ。Amazonは保留）
5. 商品名と価格が確定したものだけ、独自のテンプレートで原稿にし、元投稿の文章と似ていないかを検査する（12文字以上の一致があれば書き直し扱い）

## できないこと（2026-11-08 時点）

- 34アカウントの新着一覧の自動取得：ログインか有料の X API が必要。投稿URLを入力にする
- 商品ページの価格読み取り：この環境からは Amazon・楽天のページが中身なしで返る。価格の確定には楽天APIのキー（アプリID・アクセスキー）が必要
- 公開：このスクリプトは投稿しない
