## タイムライン記録ルール

1. **作業後に記録**: 作業が完了したら `timeline.md` と `timeline.csv` の両方に追記する
2. **日付フォーマット**: `YYYY-MM-DD`（例: 2026-04-05）
3. **ステータス**: `完了` / `対応中` / `保留` のいずれかを記入
4. **詳細**: 特記事項や確認事項があれば詳細欄に記入
