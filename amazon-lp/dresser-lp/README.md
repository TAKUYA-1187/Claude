## 3. Amazon画像規約の要点

### メイン画像（01）は実写への差し替えが必須
Amazonのメイン画像は**商品の実写プロ写真**である必要があり、イラスト・CGは認められません。
`01_main_white.png` は**構図とサイズ比率の見本**としてご利用ください。

差し替え時の要件:
- 背景は純白（RGB 255,255,255）
- 商品が画像枠の**85%以上**を占める
- テキスト・ロゴ・透かし・枠線・付属品以外の小物はすべてNG
- スツールが同梱の場合のみ、スツールを写して可

### サブ画像（02〜07）
- テキスト・図解・訴求コピーの掲載可
- 本セットは2000×2000pxで、ズーム機能に対応
- 「売れ筋No.1」「日本一」等の最上級表現は根拠なしでは記載不可

## 4. テキスト・数値の編集方法

```bash
cd amazon-lp/dresser-lp
npm install playwright          # 初回のみ
node build.js                   # dist/*.png を再生成
node sheet.js                   # 一覧シートを再生成
```

| 編集したいもの | 編集するファイル |
|---|---|
| 画像 01〜04 のコピー・レイアウト | `src/pages.js` |
| 画像 05〜07 のコピー・レイアウト | `src/pages2.js` |
| 商品イラスト・配色 | `src/parts.js` |

配色は `src/parts.js` の `P` オブジェクトに集約しています
（`gold` を変えるとアクセント色が全画像で一括変更されます）。

**日本語フォント**（Noto Sans JP / Noto Serif JP / Zen Maru Gothic）は
`~/.fonts` に配置されている前提です。環境が変わる場合は再インストールしてください。

## 5. さらに効果を上げるための推奨追加

本セットは商品イラストで構成しています。以下は**実写でしか作れない**ため、
撮影後の追加を推奨します。

1. **使用シーン画像** — 実際の部屋に設置したカット。サイズ感が最も伝わり、CVRへの寄与が大きい
2. **ディテール接写** — 引き出しのレール、鍵、LEDのタッチスイッチ部
3. **動画** — スライドミラーを動かす様子（競合1位も3本掲載）
4. **A+コンテンツ** — 本7枚の内容を横長に再構成して転用可能
