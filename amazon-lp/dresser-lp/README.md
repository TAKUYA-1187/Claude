# ドレッサー（幅80cm・LEDスライドミラー） Amazon商品ページ画像 7枚

競合1位商品（ASIN: B0CRRB9DY4）および「鏡台・ドレッサー」ランキング上位の
訴求構成を分析し、日本のAmazon家具カテゴリで実績のある**購入までの説得順**に
7枚を設計・生成したものです。

- 出力: `dist/*.png` — **2000 × 2000px**（Amazon推奨。ズーム機能の要件1600px以上を満たす）
- 一覧: `dist/00_contact_sheet.png`
- ソース: `src/*.js`（テキスト・数値はすべて編集可能）

## 0. 実写写真の入れ方（← まずここ）

このリポジトリは**写真差し替え式**です。`photos/` に決められた名前で写真を置き、
ビルドし直すだけで、イラスト部分が写真に入れ替わった完成画像が出力されます。

```bash
# 1. photos/ に写真を置く（main.jpg, hero.jpg, led_warm.jpg ...）
# 2. ビルド
node build.js
```

実行すると、どのスロットが埋まっていて、どれが未配置かを表示します。

```
写真スロット: 7 / 11 枚配置済み
未配置（イラストで代替中）:
  photos/storage_1.jpg  — 05 収納 オープンラックに収納した状態
  ...
```

- 写真が**ある**スロット → 写真を使用
- 写真が**ない**スロット → イラストで自動的に代替（見た目は崩れません）

したがって**手元にある写真から順に差し替えていける**構成です。
必要な11枚の一覧は `photos/README.md`、撮影条件は `撮影指示書.md` を参照してください。

**商品も写真もこれから調達する場合**は `画像調達プラン.md` を参照してください。
サンプル発注から入稿までの逆算スケジュール、調達ルートの比較、
サンプル到着時の実測チェックリスト（21項目）をまとめてあります。

画像生成AIで仮の商品ビジュアルを作る場合は `ChatGPT画像生成プロンプト.md` を
参照してください。**生成画像は商品ページには入稿できません**が、仕入先への
仕様イメージ伝達と撮影構図のリファレンスとして有効です。

### 写真がなくても使える画像
- **06 寸法図** — 寸法図は図解が標準です。このまま入稿できます
- **07 仕様表** — 写真不使用。数値を確認すればこのまま入稿できます

### レイアウトが自動で切り替わる箇所
`storage_1`〜`storage_4` の4枚がそろうと、**05 収納**はイラストのコールアウト版から
**写真4分割レイアウト**に自動で切り替わります。

## 3. Amazon画像規約の要点

### メイン画像（01）は実写への差し替えが必須
Amazonのメイン画像は**商品の実写プロ写真**である必要があり、イラスト・CG・AI生成画像は
認められません。`photos/main.jpg` に実物の切り抜き写真を置いてビルドし直してください。
写真を置くまでは、`01_main_white.png` は**構図とサイズ比率の見本**としてご利用ください。

なお、実物と異なるAI生成画像を商品画像に使用すると、出品停止やアカウント健全性の
問題につながります。また、競合他社の商品画像を流用することは著作権侵害にあたります。

差し替え時の要件:
- 背景は純白（RGB 255,255,255）
- 商品が画像枠の**85%以上**を占める
- テキスト・ロゴ・透かし・枠線・付属品以外の小物はすべてNG
- スツールが同梱の場合のみ、スツールを写して可

### サブ画像（02〜07）
- テキスト・図解・訴求コピーの掲載可
- 本セットは2000×2000pxで、ズーム機能に対応
- 「売れ筋No.1」「日本一」等の最上級表現は根拠なしでは記載不可

## 4. テキスト・数値の編集方法

```bash
cd amazon-lp/dresser-lp
npm install playwright          # 初回のみ
node build.js                   # dist/*.png を再生成
node check.js                   # ★ 入稿前チェック（Amazon規約の機械検証）
node sheet.js                   # 一覧シートを再生成
```

### `node check.js` — 入稿前チェック

出力画像と素材写真を解析し、Amazonで弾かれる条件を事前に検出します。
エラーがあると終了コード1を返すので、入稿前のゲートとして使えます。

| 検査項目 | 対象 | 基準 |
|---|---|---|
| 長辺の画素数 | 全画像・全素材 | 1600px以上（推奨2000px） |
| ファイルサイズ | 全画像 | 10MB以下 |
| 背景の白色純度 | メイン画像・`main` 写真 | RGB(255,255,255) |
| 商品の占有率 | メイン画像 | 枠の85%以上 |

```
  01_main_white.png  2000×2000  391KB
    ✓ 背景 純白 RGB(255,255,255)
    ✓ 商品の占有率 90%（要件 85%以上）
    ▲ メイン画像は実物の写真である必要があります
```

| 編集したいもの | 編集するファイル |
|---|---|
| 画像 01〜04 のコピー・レイアウト | `src/pages.js` |
| 画像 05〜07 のコピー・レイアウト | `src/pages2.js` |
| 商品イラスト・配色 | `src/parts.js` |

配色は `src/parts.js` の `P` オブジェクトに集約しています
（`gold` を変えるとアクセント色が全画像で一括変更されます）。

**日本語フォント**（Noto Sans JP / Noto Serif JP / Zen Maru Gothic）は
`~/.fonts` に配置されている前提です。環境が変わる場合は再インストールしてください。

## 5. さらに効果を上げるための推奨追加

本セットは商品イラストで構成しています。以下は**実写でしか作れない**ため、
撮影後の追加を推奨します。

1. **使用シーン画像** — 実際の部屋に設置したカット。サイズ感が最も伝わり、CVRへの寄与が大きい
2. **ディテール接写** — 引き出しのレール、鍵、LEDのタッチスイッチ部
3. **動画** — スライドミラーを動かす様子（競合1位も3本掲載）
4. **A+コンテンツ** — 本7枚の内容を横長に再構成して転用可能
