# 画像調達プラン ─ 商品も写真もこれから、の場合

## 結論：サンプル発注と画像依頼を「同時に」走らせる

一番よくある失敗は、サンプルが届いてから画像のことを考え始めることです。
仕入先への**サンプル発注時に画像も依頼**しておけば、サンプル到着を待つ間に
7枚を仮完成させられます。画像が先に届くことも珍しくありません。

```
週0    仕入先を選定  ─────┐
週1    サンプル発注 ──────┼──→ 同時に画像を依頼
週2-3  （待ち）           │      ↓ 画像が届いたら photos/ に入れて仮完成
週3    サンプル到着 ──────┘
週3    実測 → 仕様表・寸法図が確定
週3-4  撮影（自分 or 代行）→ 本番画像に差し替え
週4    node check.js で検証 → 入稿
```

---

## 1. 仕入先を選ぶとき（週0）

1688 / Alibaba で `化妆台 LED 滑动镜 收纳` などで検索します。単価とMOQ以外に、
**画像まわりを必ず確認**してください。後から揉めるポイントです。

- [ ] 既存の商品画像の品質（ロゴ・中国語テキストの焼き込みがないか）
- [ ] **画像の商用利用を許諾してもらえるか**（口頭ではなく、メール等の書面で）
- [ ] 白抜き（背景切り抜き）画像を出せるか
- [ ] 日本向けの出荷実績（PSE等が絡む照明付き家具では特に重要）

## 2. 調達ルートの比較

| | 自分で撮る | 撮影代行に依頼 | 仕入元の画像 |
|---|---|---|---|
| **費用** | 約1万円（機材の初期投資） | 3〜10万円 | 0円 |
| **期間** | 半日 | 1〜2週間 | 数日〜2週間 |
| **品質** | 光の管理次第 | 安定 | ばらつきが大きい |
| **メイン画像に使えるか** | ○ | ○ | 許諾＋実物一致の確認が必要 |
| **主なリスク** | 撮り直しの手間 | ほぼなし | 許諾漏れ／実物との相違 |

**推奨:** 仕入元の画像を「保険」として確保しつつ、メイン画像だけは自分で撮るか
代行に出す。メイン画像は検索結果でのクリック率を左右するうえ、規約も最も厳格です。

## 3. 自分で撮る場合の機材（実売価格の目安）

| 品目 | 価格 | 用途 |
|---|---|---|
| 白い布 or 模造紙（1.5×3m） | 約2,000円 | 背景。継ぎ目と影の線を作らない |
| クリップライト 2灯 | 約3,000円 | 左右からの光 |
| LED電球（電球色・昼白色・昼光色） | 約1,500円 | LED比較カット用 |
| トレーシングペーパー | 約500円 | 光を拡散させ、硬い影を消す |
| スマホ三脚 | 約2,000円 | **必須。**比較カットは三脚固定が前提 |
| グレーカード | 約1,000円 | ホワイトバランスの基準 |
| | **約1万円** | |

**照明なしでも撮れます。** 北向きの窓際・曇りの日の自然光は、家具撮影では
むしろ理想的です（直射日光は硬い影が出るのでNG）。その場合は三脚とグレーカードだけで十分。

カメラはスマートフォンで要件を満たせます。ただし**超広角レンズは使わないでください**
（家具が歪み、Amazonの「実物と異なる」に該当します）。標準レンズで少し離れて撮ります。

## 4. 撮影代行に出す場合

検索キーワード: `Amazon 商品撮影 代行` / `白抜き撮影 家具`

見積もり時に確認すること:
- [ ] **白抜き（切り抜き）加工が料金に含まれるか** — 別料金のことが多い
- [ ] カット単価かセット料金か（11カット必要と伝える）
- [ ] 家具・大型商品の実績があるか
- [ ] 納品形式：**長辺2000px以上のJPEG**
- [ ] 商品の送料・返送料の負担

**`撮影指示書.md` をそのまま業者に渡してください。** カットの内容・画角・光の条件を
すべて記載してあるので、追加の説明は不要です。

### 実測のコツ
- **5〜10 は必ず自分で測る。** 仕入元の記載値は外寸と内寸を取り違えていることが多く、
  ここが違うとサイズ違いの返品に直結します
- **13 は実際に点灯させて撮り、色を目視で確認。** 「3色」と書いてあっても
  実際は色差がほとんど無い製品があります
- **21 の保証は、自社で対応できる範囲だけを記載。** 現在の画像には「1年保証」が
  入っていますが、体制がなければ削除します

## 6. 画像が1枚でも届いたら

全部そろうのを待つ必要はありません。`photos/` に置いてビルドすれば、
その部分だけ実写に変わり、残りはイラストのまま破綻せず出力されます。

```bash
node build.js    # 写真のあるスロットだけ差し替わる
node check.js    # 解像度・背景・占有率を検証
```
