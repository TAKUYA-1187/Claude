# 撮影指示書 ─ ドレッサー 幅80cm（Amazon商品ページ用）

必要なカットは **11枚**。これを `photos/` に置いて `node build.js` を実行すると、
デザイン済みの7枚が完成します。

---

## 共通の撮影条件

| 項目 | 指定 |
|---|---|
| 解像度 | 長辺 **2000px以上**（推奨3000px）。JPEG品質90以上 |
| 背景 | 白ホリゾント、または白い壁＋白い床。しわ・影の線が出ないように |
| 光 | 左右から拡散光（ソフトボックス2灯）。**商品の白を白く写す**のが最優先 |
| ホワイトバランス | 全カットで固定。グレーカードで基準を取る |
| カメラ | 三脚固定。**焦点距離50〜85mm相当**（広角は家具が歪むためNG） |
| 高さ | カメラ位置は商品の中央高さ（床から約65cm）。見上げ・見下ろしを避ける |
| 加工 | 明るさ・WB補正まで。**形状の加工や合成はしない**（実物と相違が出るため） |

> **重要:** 03・04のセットは「比較」が伝わることが目的です。
> **同じ画角・同じ位置・同じ露出**で撮り、変わるのは光の色／鏡の位置だけにしてください。
> 途中で三脚を動かすとカットが揃わなくなります。

---

## カット別の指示

### ① `main` — メイン画像用（最重要）
- 商品**正面**、スツールを手前に添える（同梱の場合のみ）
- 背景は**純白（RGB 255,255,255）に切り抜き**。影も落とさない
- 商品が枠の**85%以上**を占めるように（正方形でトリミング）
- **テキスト・ロゴ・透かし・小物は一切写さない**（Amazon規約）
- LEDは**点灯させない**か、ごく弱く。商品の白色が正しく見えることを優先

### ② `hero` — 全体イメージ
- **斜め45度**から。奥行き・立体感が出る角度
- LEDを点灯（電球色）、棚に化粧品を少量ディスプレイ
- 縦長（3:4〜4:5）。**背景透過PNG**にできると仕上がりが最も良い

### ③〜⑤ `led_warm` / `led_neutral` / `led_cool` — 3色比較
- **ミラー部分のクローズアップ**（横長4:3）
- 三脚固定のまま**光の色だけ切り替えて3枚**連続で撮影
- 部屋を暗くし、LEDの色が正確に出る状態で
- カメラのWB・露出は**マニュアル固定**（オートだと3枚とも同じ色に補正されてしまう）
- ファイル名と光の色を必ず一致させる（warm=電球色 / neutral=昼白色 / cool=昼光色）

### ⑥⑦ `mirror_closed` / `mirror_open` — スライド2WAY
- 商品**正面**、縦長（3:4）
- `mirror_closed`：鏡を中央（ドレッサーとして使う位置）
- `mirror_open`：鏡を横にスライドし、収納が見えている状態
- **三脚を動かさず2枚**。並べたときに鏡だけが動いて見えるのが理想

### ⑧〜⑪ `storage_1`〜`storage_4` — 収納ディテール（横長4:3）
| ファイル | 内容 |
|---|---|
| `storage_1` | オープンラック3段に化粧水・香水を並べた状態。**高さのあるボトルが入る**ことが伝わるように |
| `storage_2` | 鍵付き引き出しを開けた状態。**鍵穴と鍵**が見えるように |
| `storage_3` | 引き出し3杯を階段状に開けた状態。中にコスメを入れて**容量が伝わる**ように |
| `storage_4` | スツールを足元に収めた状態。**省スペース感**が伝わる引き の画角で |

## 追加で撮っておくと効果が大きいカット

本セットには組み込んでいませんが、Amazonでの成果に直結します。

1. **使用シーン** — 実際の部屋に設置し、人物が座っているカット。サイズ感が最も伝わる
2. **動画** — 鏡をスライドさせる10〜20秒。競合1位も3本掲載しています
3. **接写** — 引き出しレール、LEDのタッチスイッチ、天板の質感

## サプライヤーに写真を依頼する場合

工場・仕入元から画像を受け取る場合は、**商用利用の許諾を書面で**取得してください。
他社の商品ページ画像の流用は著作権侵害になります。

### 依頼文テンプレート（中国語 / 1688・Alibaba向け）

```
您好。我们准备在日本亚马逊上架这款梳妆台，需要以下产品图片，请协助提供：

1. 白底去背图（正面，整体，含凳子）— 用于主图
2. 45度角整体图（LED开灯，暖光）
3. 镜子特写 3 张：暖光 / 自然光 / 冷光（三张请用同一机位、同一曝光拍摄）
4. 镜子在中间的正面图，以及镜子滑到旁边的正面图（同一机位拍摄两张）
5. 收纳细节 4 张：开放层架、带锁抽屉（露出钥匙）、三个抽屉打开、凳子收进桌下

要求：长边 2000px 以上，JPEG，无水印、无文字、无logo。
另外，请确认我们可以将这些图片用于亚马逊商品页面的商业用途，
并以书面形式（邮件即可）给予授权。谢谢！
```

### 依頼文テンプレート（日本語）

```
下記の商品画像をご提供いただけますでしょうか。

1. 白背景・切り抜き（正面／全体／スツール込み）— メイン画像用
2. 斜め45度からの全体（LED点灯・電球色）
3. ミラー部のアップ3枚：電球色／昼白色／昼光色（同一画角・同一露出で）
4. ミラー中央の正面／ミラーを横にスライドした正面（同一画角で2枚）
5. 収納ディテール4枚：オープンラック／鍵付き引き出し（鍵が見える）／
   引き出し3杯を開けた状態／スツールを足元に収めた状態

条件：長辺2000px以上、JPEG、ウォーターマーク・文字・ロゴなし
あわせて、Amazon商品ページでの商用利用について書面でのご許諾をお願いします。
```
