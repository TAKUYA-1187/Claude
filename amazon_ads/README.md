# Amazon広告 運用最適化ツール

検索用語レポートを入れると、**除外キーワード・刈り取り・入札調整**の推奨リストをCSVで出力するツールです。
アカウントの現状診断と即実行アクションは [analysis_2026-07-07.md](analysis_2026-07-07.md) を参照してください。

## 使い方

### 1. レポートをダウンロード

Amazon広告管理画面 → 「測定とレポート」→「広告レポート」→ レポートを作成:

- レポートタイプ: **スポンサープロダクト → 検索用語**
- 期間: 過去30日（データが少ない場合は60日）
- 形式: xlsx

補助的に「ターゲティング」レポートも同じ手順で取得すると、商品ターゲティング（ASIN）の入札調整候補も出ます。

### 2. 実行

```bash
cd amazon_ads
python main.py ~/Downloads/検索用語レポート.xlsx --target-acos 0.20
```

`--target-acos` には自分の目標ACOSを指定します（損益分岐ACOS＝広告費控除前の粗利率より少し低い値）。

### 3. 出力を管理画面に反映

`output/` に4つのCSVが出ます:

| ファイル | 内容 | 管理画面での操作 |
|---|---|---|
| `negatives.csv` | 除外キーワード候補 | 該当キャンペーンの「除外キーワード」にネガティブ完全一致で追加 |
| `harvests.csv` | 刈り取り候補 | 完全一致キャンペーンにキーワード追加（推奨入札つき）＋ 元キャンペーンで除外 |
| `bid_up.csv` | 入札引き上げ候補 | 該当ターゲットの入札を `suggested_bid` に変更 |
| `bid_down.csv` | 入札引き下げ候補 | 同上 |

## ルールの考え方

- **除外**: 10クリック以上で注文ゼロの検索語は、統計的に「合っていない」と判断して止血する
- **刈り取り**: オート/部分一致で2件以上売れた検索語は、完全一致に移して入札を個別コントロールする（オート側は除外して重複配信を防ぐ）
- **入札**: 理論入札 = クリックあたり売上 × 目標ACOS。ただし一度の変更は±30%以内に制限し、週次で段階的に寄せる
- クリック5件未満のターゲットは判定しない（ノイズ）

閾値はすべて `config.py` またはコマンドライン引数で変更できます。

## 週次ルーティン（15分）

1. 検索用語レポート（過去30日）をダウンロード
2. このツールを実行
3. CSVの推奨を管理画面に反映
4. アカウント全体のACOSが目標±5ptか確認

## 必要パッケージ

xlsxを読む場合のみ `openpyxl` が必要です（リポジトリ直下の `requirements.txt` に含まれています）。CSVなら標準ライブラリのみで動きます。
