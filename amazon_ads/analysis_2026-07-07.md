# Amazon広告 アカウント診断と改善プラン（2026-07-07時点）

対象: LIFE STAR 1187 / スポンサー広告（日本） / 集計期間 2026/06/07〜2026/07/07

## 結論（最重要ポイント）

**このアカウントの問題は「効率」ではなく「スケール不足」です。**

- 全体ROAS **9.70**（ACOS換算 **約10.3%**）は物販アカウントとして非常に健全。広告は売上に直結している（広告経由売上 ¥1,000,720 / 費用 ¥103,160）。
- 一方で、**全キャンペーンの検索結果上部インプレッションシェアが5%未満**。つまり入札が弱く、最も転換率の高い掲載面（検索結果最上部）をほぼ取れていない。
- 日予算合計 約¥14,500 に対し実消化は約¥3,300/日（**消化率23%**）。予算ではなく**入札額がボトルネック**。
- 「広告が販売に直結していない」と感じる原因は、広告費が絞られすぎていて売上の絶対額が伸びていないため。効率を維持したまま**露出を2〜3倍に増やす**のが正しい打ち手。

## 今すぐ管理画面で行うアクション（優先順）

### 1. 机上ラックMANUAL_EXACT の入札を引き上げる（効果: 大）

ROAS 12.12 と最も効率が良いのに、月間費用が¥11,240しかなく予算の1割しか使えていない。
- 全キーワードの入札を **+25〜30%**（CPC実績¥24 → 入札¥35〜40目安）
- キャンペーン設定 → 掲載枠(プレースメント)の「検索結果のトップ（最初のページ）」を **+50〜75%** に設定（現在0%）
- 入札戦略を「動的な入札 – アップとダウン」に変更
- 1週間後にACOSを確認し、目標ACOS（下記参照）以内なら さらに+15%

### 2. ベッドテーブル キーワード（オート）の刈り取り運用を開始（効果: 大）

購入55件の主力キャンペーン。オートに依存したままだと入札コントロールができない。
- 広告レポート → 検索用語レポート（過去30〜60日）をダウンロード
- **注文が2件以上付いている検索語** → 「ベッドテーブル」用のマニュアル完全一致キャンペーン（新規作成）に移管し、オート側では除外(ネガティブ完全一致)に追加
- **10クリック以上で注文0の検索語** → 除外キーワード（ネガティブ完全一致）に追加
- この作業は同梱の `amazon_ads` ツールで自動判定できます（後述）

### 3. 机上ラックのオートキャンペーンを再開（効果: 中）

机上ラックは完全一致キャンペーンしか動いておらず、**新しい検索語を発掘する経路がない**。
- 「机上ラック キャンペーン」（オート、一時停止中）を再開
- 日予算 ¥1,000、入札は控えめ（¥20〜25）でスタート
- MANUAL_EXACTで配信済みのキーワードはネガティブ完全一致に入れて重複配信を防ぐ
- 月1回、検索用語レポートから成果語をMANUAL_EXACTへ刈り取り

### 4. ベッドテーブル商品ターゲティングの精査（効果: 中）

- ターゲティングレポートをダウンロードし、ASIN単位でROASを確認
- ROASが目標超えのASIN → 入札+20%／注文ゼロで費用がかさむASIN → 除外
- 「机上ラック_競合」も同様（ROAS 6.64は4本中最低。粗利率30%未満の商品ならCPC上限を下げる）

### 5. 目標ACOSを決める（運用の土台）

- 損益分岐ACOS = 商品の粗利率（広告費を除く）。例: 粗利率30%なら ACOS 30% までは利益が出る
- 現在の実績ACOS 10.3%は、成長フェーズとしては**絞りすぎ**の水準
- 推奨: **目標ACOS 20%** を上限目安に露出を拡大 → 売上規模を伸ばしつつ利益を確保
- オーガニック順位への波及（広告経由の販売実績がSEOを押し上げる）を考えると、多少ACOSが上がっても売上総額を伸ばす価値が高い

## 週次運用ルーティン（15分/週）

1. 検索用語レポート（過去30日）をダウンロード

3. 推奨リストを管理画面に反映
4. キャンペーン全体のACOSが目標±5ptに収まっているか確認し、予算・入札を微調整
