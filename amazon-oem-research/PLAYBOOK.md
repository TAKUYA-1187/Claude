# Amazon中国輸入OEM 日次リサーチ プレイブック

毎朝7時に実行する日次リサーチの手順書。このファイルはセッションをまたいで参照される「永続的な指示書」である。

## リサーチ条件（固定）

- **ターゲット**: Amazonで月間200個以上売れる高回転が見込める、中国輸入OEM向き商品
- **利益条件**: 販売価格に対し、1688/アリババ卸価格ベースの仕入原価（国際送料・関税・FBA手数料込み）が **50%以内**
- **サイズ条件**: 梱包サイズ **160サイズ以上**（3辺合計160cm以上）の大型商品を優先
- **候補カテゴリ**: 大型アウトドア/キャンプ、大型ペット用品、フィットネス器具、収納・家具、ベビー・キッズ大型、季節家電周辺

## 誠実性ルール（厳守）

1. Keepa/Jungle Scout/セラースプライト、Amazon実売データ、1688/アリババのリアルタイム卸価格には直接アクセスできない。
2. 実在ASIN・「月間販売数◯個」・「仕入単価◯円」などの**検証できない数字を確定事実として捏造しない**。
3. WebSearch/WebFetchで確認できた実在情報（トレンド・季節需要・実売価格帯・話題カテゴリ）のみを根拠とし、推測は「仮説」「要検証」と明記する。
4. レポート末尾に「Web調査ベースの仮説であり検証済み確定データではない」注記を必ず入れる。

## 日次の作業手順

1. `amazon-oem-research/reports/` の直近レポートを読み、前日までの切り口を確認（重複回避）。
2. WebSearchで当日の日付・季節を踏まえた需要トレンドを調査（3〜5クエリ）。
   - カテゴリローテーション例: 月=アウトドア / 火=ペット / 水=収納・家具 / 木=フィットネス / 金=ベビー・キッズ / 土=季節家電 / 日=横断・週次まとめ
3. 有望カテゴリ・商品タイプを2〜3件に絞り、各々について整理:
   - 想定販売価格帯（実売ページ・ランキングから確認できたもの）
   - 原価半値以下の成立可能性（仮説）
   - 160サイズ以上か / FBA区分（大型 <160cm・18.9kg未満 / 特大型 160〜400cm・18.9〜50kg）
   - OEM差別化の切り口
   - 参入リスク
   - 次に必要な検証ステップ
4. レポートを `amazon-oem-research/reports/YYYY-MM-DD.md` に保存。
5. コミットして `claude/relaxed-mendel-0s7ln5` にプッシュ。
6. ユーザーに要約を報告。

## 固定の検証フロー（ユーザー側で確定させる手順）

1. Keepa/セラースプライトで「月販200個以上 × 大型」フィルター → ASIN候補抽出
2. FBA料金シミュレーターで2026年新手数料の配送代行手数料を確定
3. 1688/アリババの**画像検索**で同型品を逆引き → 卸単価取得
4. 「国際送料・関税込み原価 ≦ 販売価格の50%」フィルター
5. 出品者数・レビュー数で参入難易度判定（過当競争は除外）

## 既知の市場ファクト（2026-07時点、要定期更新）

- **2026-06-15 FBA改定**: 大型=160cm未満・18.9kg未満 / 特大型=160〜400cmまたは18.9〜50kg。服飾以外の大型/特大型の配送代行手数料は1〜9月期 約25%引き下げ、10〜12月期 約10%引き下げ。→ 大型戦略への追い風。
- 中国輸入OEMの利益率相場: 40〜50%（単純転売は15〜30%）。
- 1688は3段階価格（小ロット高め/中ロット標準/大ロット最安）。代行業者経由が前提。
