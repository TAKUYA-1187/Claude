## 本文

Amazonで売上は伸びているのに、利益が残らない。利益は出ているはずなのに、通帳の残高が減っていく。

私はAmazonで13か月、売上約2,235万円を売り、広告費を引いた時点で利益はマイナスでした。そのとき、どこでお金が消えていたかを特定するために作った表を、誰でも使える形にしたのがこのキットです。

月ごとの数字を入れるだけで、次の4つがわかります。

1. **1個あたりの利益**：売れば売るほど損をしていないか
2. **お金が消えた場所の順位**：原価・販売手数料・FBA手数料・保管料・広告・返金のうち、どこがいちばん大きいか
3. **在庫と現金**：利益は出ているのに、在庫を積みすぎて現金が減っていないか
4. **改善の効果**：原価を5%下げたら、返品を3割減らしたら、1個あたりの利益がいくら変わるか

| シート | できること |

## 見本：利益は出ているのに、現金が41万円減っていた

キットに入っている架空の見本（6か月）を、内訳シートで見るとこうなります。

| | 6か月の合計 |
| --- | --- |
| 売上 | 9,384,000円 |
| 利益 | 668,300円（1個あたり約1,020円） |
| 広告前利益率 | 約12.2% |
| **現金の増減** | **−410,000円** |

利益は67万円出ていますが、現金は41万円減っています。月次シートを見ると、6月と9月に大量に仕入れて、9月末の在庫は今の販売ペースの約9.4か月分。6か月のうち4か月が「注意」です。利益だけを見ていると、この状態に気づけません。

改善シミュレーションで「着地原価−5%」「返品・返金−30%」にすると、1個あたりの利益は約1,020円から約1,600円になります。

## こんな人に向いています

- Amazonで自社商品（OEM・輸入品）を売っていて、月の売上が数十万円以上ある人
- 売上は伸びているのに、利益や現金が残っている実感がない人
- セラーセントラルのレポートは見ているが、何が問題かを数字で言えない人

## 向いていない人

- まだ販売を始めていない人：売れる商品の見つけ方は入っていません
- 相乗り出品・転売が中心で、1商品の販売期間が短い人：月ごとの推移を見る表なので、効果が出にくいです
- 「これを使えば利益が出る」ものを探している人：原因を特定する道具で、直す作業は自分でする必要があります

## 数字の集め方（1か月分で約15分）

| 入れる項目 | どこから取るか |
| --- | --- |
| 売上・販売手数料・FBA配送手数料・在庫保管手数料・返金額 | セラーセントラル →「ペイメント」→「レポートリポジトリ」→「日付範囲別レポート」（その月の1日〜末日）。マイナス表示の項目はプラスに直して入れる |
| 販売個数・返品個数 | 「ビジネスレポート」の注文商品数と、「返品レポート」 |
| うち再販不可 | 返品レポートの返品理由・状態（販売不可）を確認する |
| 広告費 | 広告コンソールの、その月の広告費（入金から引かれていても、カードで払っていても入れる） |
| 1個あたり着地原価 | 自分の仕入れの記録。工場への支払い＋国際送料＋関税＋通関・検品・国内配送 ÷ 個数 |
| 月末の在庫個数 | 「在庫レポート」の、月末時点の販売可能＋入荷中の個数 |
| 仕入れの支払額 | その月に工場・業者に実際に払った額（前払い金も含む） |
| Amazonからの入金額 | その月に口座に入った金額 |

## 判定の見方と、直す順番

月次シートは次の順に見ます。

1. **1個あたり利益がマイナスの月はないか**（赤字）：あれば、その月の内訳から見る
2. **広告前利益率が基準（初期値10%）を下回っていないか**（注意）：薄いと、広告と返品の少しの増加で赤字になる。私の13か月はここが約2.6%でした［要確認：看板記事の数字の確認後に確定］
3. **返品率が基準（初期値5%）を超えていないか**（注意）：不良・商品説明と実物のズレ・梱包を点検する
4. **在庫月数が基準（初期値3か月）を超えていないか**（注意）：現金の増減がマイナスなら、次の発注を減らす

直すときは、内訳シートの順位の上から手を付けます。順位がいちばん高いのは、ほとんどの場合「商品原価」です。原価の直し方は、工場との交渉・発注ロット・梱包サイズ（FBA手数料の区分）の見直しです（無料記事「中国工場の見積もりは単価で比べない」）。

**広告は最後に触ります。** 広告前の利益が薄いまま広告を止めると、広告で取れていた売上が落ちるだけで、赤字は残りやすいからです。

## 改善シミュレーションの使い方

黄色のセルに、変えたい割合を入れます（例：着地原価 −5%、返品・返金 −30%）。

- 販売価格を上げると、販売手数料と返金も同じ割合で増える計算になっています
- 販売個数は変わらないものとして計算します。値上げで売れる数が減る影響は、自分で見込んでください
- 「いま」の列は、内訳シートの期間の平均です。直近の数か月だけで見たいときは、月次シートに直近の月だけを入れたコピーを作ってください

## 実例：私の13か月

［要データ：オーナーの13か月の月別の数字を「実例」シートに入れ、ここに次の3点を書く］

1. 月次の判定がどう並んだか（赤字・注意が出始めた月）

## よくある質問

**Q. 複数の商品を売っている場合は？**
まず全体で1枚作り、内訳を見ます。原因の大きい商品がわかったら、その商品だけのファイルを作ると、商品ごとの問題が見えます。

**Q. 消費税はどう扱う？**
売上は税込で入れます。消費税の扱い（課税事業者か、簡易課税か）で実際の利益は変わるので、申告方法に合わせて読み替えてください。この表は、固定費・税金を引く前の、商品の収益力を見るためのものです。

**Q. 月の途中でも使える？**
使えますが、レポートは月単位で入れたほうが、月ごとの比較が正確になります。
