## 3. 仕入れ判定シートを公開する（15分）

パソコンで行う（スマホのアプリでは Excel を添付できないことがある）。

1. このフォルダのドキュメント「kaitori_shiire_sheet.xlsx（ダウンロードはこちら）」のリンクから、Excel をパソコンに保存する
2. note の右上「投稿」→「テキスト」
3. ドキュメント「02 有料 仕入れ判定シート」のタイトルを入れ、本文を貼る
4. 「――― ここから有料 ―――」の行を消し、その位置に「有料エリア」の線を入れる
5. 有料エリアの「ダウンロード」の見出しの下で「＋」→「ファイル」から Excel を添付
6. 「公開に進む」→ 価格 980円、ハッシュタグを入れて公開
7. 公開した URL を Claude に送る
