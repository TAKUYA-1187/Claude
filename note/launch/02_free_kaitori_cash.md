## 本文

買取せどりは、売値（買取価格）が仕入れる前にわかるので、赤字になりにくい手法です。それでも、カードの引き落とし日に口座の残高が足りなくなる人がいます。

帳簿では利益が出ているのに、現金が足りない。この記事では、それが起きる仕組みを、1か月の数字で分解します。

## 1か月の数字で見る

10月に、クレジットカードで30万円分を仕入れたとします。カードは月末締め・翌月27日払いです。

仕入れた時点の見込みはこうでした。

| 項目 | 金額 |
| --- | --- |
| 仕入れ額（11月27日に引き落とし） | 300,000円 |
| 見込み利益（ポイント込み、10%） | 30,000円 |
| うち現金の利益（5%） | 15,000円 |
| うちポイント（5%） | 15,000円 |

3万円の利益が出る計算です。ところが11月27日の時点で、実際に戻っていた現金はこうなりました。

| 項目 | 金額 |
| --- | --- |
| 予約商品と、箱がいっぱいになるのを待っていた未発送の商品 | 60,000円分（まだ現金になっていない） |
| 発送して入金された商品の仕入れ額 | 240,000円分 |
| その入金額（現金の利益5%込み） | 252,000円 |
| 減額 | −5,000円 |
| **11月27日までに戻った現金** | **247,000円** |

引き落としは30万円。**利益は3万円出ているのに、支払日には5万3,000円足りません。**

## なぜ足りなくなるのか

### 1. ポイントは、カードの支払いに使えない

見込み利益3万円のうち半分はポイントでした。ポイントは次の仕入れには使えても、カードの引き落としには使えません。利益の計算にポイントを混ぜると、現金の見通しを誤ります。

### 2. 「まだ発送していない商品」は、支払日に間に合わない

予約商品や、送料を下げるために箱がいっぱいになるのを待っている商品は、仕入れ代金だけ先に引き落とされます。送料の節約のつもりが、支払日の現金不足を作ります。

### 3. 減額・価格の下落は、入金額を直接減らす

減額は利益を減らすだけでなく、支払日に戻る現金を減らします。利幅が薄いほど、少しの減額で足りなくなります。

### 4. 仕入れを増やした月ほど、足りなくなる

翌月の引き落としは「先月の仕入れの合計」です。仕入れを増やした月は、引き落としも増えます。そのときに未発送や減額が重なると、不足が一気に大きくなります。

## 毎月確かめること：支払日までに、いくら戻るか

見るべき数字は、利益ではなく次の2つです。

1. **次の引き落とし額**：先月のカードの仕入れの合計
2. **支払日までに戻る見込みの現金**：発送済み・査定済みの商品の入金見込み。未発送の商品とポイントは入れない

2が1を下回りそうなら、次の仕入れを減らすか、未発送の商品を先に発送します。

## 足りなくならないための3つの習慣

1. **ポイントを利益に混ぜない**：仕入れの判断も、現金の利益だけで行う
2. **未発送の商品を、支払日から逆算して発送する**：「箱がいっぱいになってから」より、支払日に間に合うことを優先する
3. **仕入れを増やすのは、先月の入金を確認してから**：先月の仕入れがいくらで戻ったかを見てから、今月の仕入れ額を決める

## まとめ

- 利益が出ていても、ポイント・未発送・減額で、支払日の現金は足りなくなる
- 見るのは利益ではなく「次の引き落とし額」と「支払日までに戻る現金」
- 仕入れの判断は現金の利益で行い、未発送の商品は支払日から逆算して送る
