## 本文

中国の工場から見積もりを2社取ると、つい単価の安いほうを選びたくなります。でも、単価が安い工場のほうが、最終的に1個あたりの原価が高くなることはよくあります。

この記事では、見積もりを比べるときに単価以外に見る7項目と、「売れる1個あたりの原価」で比べる計算を、例で示します。

## 単価以外に見る7項目

| # | 項目 | 何が変わるか |
| --- | --- | --- |
| 1 | 取引条件（EXW・FOB・DDP など） | どこまでの費用が単価に入っているか。EXW は工場渡し、FOB は中国の港で船に載せるまで、DDP は日本の指定場所までの輸送と関税まで売り手が負担 |
| 2 | 金型代・版代・サンプル代 | 初回だけかかる費用。初回の発注数で割ると1個あたりに効く |
| 3 | 梱包の仕様と箱のサイズ | 国際送料と、Amazon の FBA 手数料のサイズ区分に効く。数センチの差で区分が変わることがある |
| 4 | 最小発注数（MOQ）と数量ごとの単価 | 在庫を何か月分持つことになるか。保管料と資金に効く |
| 5 | 支払条件 | 前払いの割合と時期。資金繰りに効く |
| 6 | 不良率の目安と、不良が出たときの扱い | 返金か、次回発注での無償補填か、何もしないか。売れる個数が変わる |
| 7 | リードタイム | 生産と輸送にかかる日数。欠品と在庫の持ちすぎの両方に効く |

## 計算例：単価が150円安い工場は、得だったか

同じ商品を1,000個発注する例です（数字は説明用の例です。関税・通関費は両社で同じ条件として比較から外しています）。

| | A社 | B社 |
| --- | --- | --- |
| 単価（FOB） | 1,800円 | 1,950円 |
| 金型代 | なし | 50,000円（1,000個で割ると50円） |
| 国際送料（1個あたり） | 450円（箱が大きい） | 380円（箱を小さく設計） |
| 不良率と扱い | 3%、補償なし | 1%、次回発注で無償補填 |
| FBA 手数料への影響 | 箱が大きく、1つ上のサイズ区分になり1個あたり +200円 | 影響なし |

売れる1個あたりの原価に直します。

- **A社**：（1,800円＋450円）× 1,000個 ÷ 売れる970個 ＋ FBA の増加分200円 ＝ **約2,520円**
- **B社**：1,950円＋50円＋380円 ＝ **2,380円**（不良分は無償補填されるので、売れる個数は実質1,000個）

単価が150円安いA社のほうが、**売れる1個あたりでは約140円高く**なりました。1,000個なら約14万円の差です。

## 見積もりをもらう前に、工場に伝えておくこと

比べられる見積もりをもらうには、依頼の段階で条件をそろえます。

1. 取引条件（例：FOB で、出荷港も指定）
2. 発注数（例：500個・1,000個・3,000個の3段階）
3. 梱包の仕様（1個ごとの箱の寸法の上限、外箱1箱あたりの入数）
4. 不良の基準と、不良が出たときの扱い（返金か、次回補填か）
5. 支払条件の希望（前払いの割合）

条件がそろっていない見積もりは、比べているつもりで、違うものを比べています。

## まとめ

- 単価ではなく「売れる1個あたりの原価」で比べる
- 梱包サイズ・不良の扱い・初回の費用で、単価の差は簡単に逆転する
- 依頼の段階で、取引条件・数量・梱包・不良の扱いをそろえる

## 自分の見積もりで計算したい人へ

2社以上の見積もりを入れると、売れる1個あたりの原価を自動で比べる表と、工場に送る依頼文・検品基準・不良補償の交渉文（日本語・中国語）をまとめたキットを準備しています。
