## 1. 戦略の要約

1. **1つのテーマに絞る**：「物販で、売れても利益が残らない原因を数字で見つけて直す」。オーナーの実体験（Amazon 13か月の売上約2,235万円で赤字、中国OEM、買取せどり、価格比較の自動化）がそのまま一次情報になる
2. **文章ではなく道具を売る**：Excel の判定表・点検表、交渉文テンプレート、チェックリスト。note 公式の分析でも、売れる実用記事は文字数と関係がない
3. **無料記事で検索から集め、テンプレートで稼ぎ、メンバーシップで積み上げる**：note の長く読まれる記事の流入は検索が中心。単品で信頼を作り、継続課金を月100万円の土台にする
4. **ジャンルを広げるのは、本線が回ってから**：高級ブランド（ロレックス・エルメス）は別アカウントで検証する。医薬情報担当者（MR）の経験は、規約・守秘のリスクがあるので当面扱わない

## 6. 集客の導線

```
検索（Google・note内検索）→ 無料記事 → 有料記事の無料部分 → 購入 → 上位商品・メンバーシップ
                ↑
ブログ「せどり実務ノート」の記事末の案内（ブログ側の担当）／ X での告知（任意）
```

- **検索**：無料記事は題名に検索語を入れる。長期の流入の中心になる
- **ブログ**：ブログの記事の最後に、関係する note 商品の案内を出してもらう（11章）
- **note 内**：記事の最後に関連記事・マガジンへのリンクを入れて回遊させる。ハッシュタグは5個まで、検索される言葉を使う
- **X**：アカウントがあれば、公開日に1回、中身の一部（表の画像など）を見せて告知する。なくても始められる

## 9. 品質と規約のルール

- 体験談・実績・数字は、オーナーから受け取った事実だけを書く。**作らない**
- 「誰でも」「確実に」「月収○万円」を使わない（note は情報商材を禁止している）
- 無料部分に「何が手に入るか」「向いていない人」を必ず書く。買ってから「思っていたのと違う」を起こさない（返金を防ぎ、高評価につながる）
- テンプレート・Excel は、計算を検算してから出す
- 取引先・工場・商品・個人を特定できる情報は伏せる
- 高評価は購入者が任意で押すもので、100%は約束できない。目標は「購入者の40%以上が高評価」

## 10. ChatGPT が作った原稿（54本）の扱い

ChatGPT のワークで、50ジャンル・54本の原稿（Markdown・HTML・PDF・zip）が作られたが、このリポジトリには入っていない。

- **本線（物販）に合うもの**：Amazon の利益・現金・在庫、中国OEM、部品欠品・返品対応など → 事実を確認して P2・P3 や無料記事に使う
- **別アカウント候補**：ロレックス・エルメス → 本線が回ってから（7か月目以降）
- **使わない**：オーナーの経験がないジャンル。中身の浅い有料記事は、低評価・返金・規約違反のもとになる

オーナーが Google ドライブにファイルを置けば、Claude が1本ずつ仕分ける（12章）。
