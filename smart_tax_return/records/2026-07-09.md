#### 提出済みかどうかの見分け方（5分でできる）

会計士から共有されている `.01-03月分(4月末日まで期限)` > `10.売上[Amazonセラー]` を開いて、
中身を数えるだけで判定できる。

| 見えるもの | 判定 |
|---|---|
| CSV 3件のみ（1・2・3月の月別トランザクション） | **未提出**。PDF 3件を追加する |
| CSV 3件 + PDF 3件 | 提出済み。会計士に完了を伝えるだけ |
| それ以外（月が欠けている等） | 欠けている月を特定してから取得する |

比較用に `.04-06月分(7月末まで期限)` > `10.売上[Amazonセラー]` を開くと、
**CSV 3件 + PDF 3件 = 計6件**になっているはず。これが目指す形。

#### 未提出だった場合の手順

```
1. Amazonセラーセントラル → レポート → ペイメント
   - 月別トランザクションレポート（CSV）: 既に提出済みなので取得不要
   - 期間別概要レポート（PDF）: 2026年1月 / 2月 / 3月 の3件を出力
2. `2026_領収書/202604提出資料/` に保存する（1-3月分のステージング）
3. Drive `.01-03月分(4月末日まで期限)` > `10.売上[Amazonセラー]` を開く
4. アップロード前に中身を列挙して、PDFが既に無いことを確認する（上書きではなく追加なので重複する）
5. 新規 → ファイルのアップロード → 3件を投入
6. トーストの緑チェックと件数を確認し、再列挙して6件になったことを確かめる
7. スマート確定申告へ完了連絡（テンプレは references/accountant-feedback.md）
   ファイル名を3件とも書き、「4-6月分と同じ様式で1-3月分にもPDFを追加した」と伝える
```

> フォルダURL（フォルダID）はこの公開リポジトリには書かない。ユーザーから都度共有してもらう。
