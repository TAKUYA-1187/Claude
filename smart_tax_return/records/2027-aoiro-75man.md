# 令和9年分 青色申告特別控除 75万円対応（届出書の提出）

| | |
|---|---|
| 前提 | 過去はe-Tax送信のみで65万円控除を受けていた（＝届出書は未提出と判断） |
| 必要な手続き | 「国税関係帳簿の電磁的記録等による保存等に係る65万円の青色申告特別控除・過少申告加算税の特例の適用を受ける旨の届出書」の提出 |
| 手続コード | A1-15、H4-9 |
| 法定の提出期限 | **令和10年3月15日**（令和9年分の確定申告期限） |
| 実務上の期限 | **令和8年12月31日** — 令和9年1月1日から要件を満たした記帳が必要なため |
| 効果 | 青色申告特別控除 65万円 → 75万円（所得税20%＋住民税10%なら年およそ3万円の減税） |
| 記録日 | 2026年9月19日 |

---

## 手順0: 本当に未提出かを確認する

既に提出済みなら手続きは不要。**確認せずに進めない。**

| 確認先 | 見るもの | 限界 |
|---|---|---|
| **スマート確定申告（会計士）** | 提出控えの有無 | **最も確実。まずここに聞く** |
| e-Tax メッセージボックス | 送信結果・受信通知に「申請・届出」の受信通知があるか | **書面で提出していた場合は残らない** |
| マネーフォワード クラウド確定申告 | メッセージボックスでe-Taxの受信通知を確認できる | 申告書の電子申告の記録のみ。**届出書はMFの機能外なので、ここでは判定できない** |

**「見つからないこと」は「提出していないこと」の証明にならない。** 書面提出の可能性が残る。
判断がつかないまま期限を逃すのが最悪なので、迷ったら所轄税務署に本人から電話で確認する。

---

## 手順1: 届出書の記入内容

様式は国税庁の配布PDF（青色申告特別控除の案内ページにある「届出書の様式」）を使う。
欄名は様式が正。以下は各欄に何を書くかの対応表。

| 欄 | 記入内容 |
|---|---|
| 提出年月日 | 提出する日 |
| ◯◯税務署長 | 納税地を管轄する税務署 |
| 納税地・電話番号 | 本人記入 |
| 氏名・フリガナ・生年月日 | 本人記入 |
| 個人番号（マイナンバー） | 本人記入。**この番号は誰にも共有しない。Claudeにも送らないこと** |
| 職業・屋号 | 本人記入 |
| 特例国税関係帳簿の種類 | **仕訳帳・総勘定元帳**（この2つで要件を満たす。他の帳簿を足してもよいが、足した帳簿はすべて優良要件を満たす必要がある） |
| 備付けを開始する日 | **令和9年1月1日** |
| 使用する電子計算機・ソフトウェア | マネーフォワード クラウド確定申告（JIIMA「電子帳簿ソフト法的要件認証」取得済み） |
| 適用を受けようとする年分 | 令和9年分以後 |
| 関与税理士 | 代理提出を依頼する場合は担当税理士 |

> 帳簿の種類は**欲張らない**。書いた帳簿はすべて優良な電子帳簿の要件を満たしている必要がある。
> 仕訳帳・総勘定元帳の2つで75万円控除の要件は満たせる。

---

## 手順2: 提出方法

| 方法 | 手順 |
|---|---|
| **会計士に代理提出を依頼** | 最短。スマート確定申告に依頼できるか確認する |
| e-Tax | e-Taxソフト（WEB版）の「申請・届出」から該当手続を探す。WEB版で扱えなければe-Taxソフト（ダウンロード版）を使う |
| 書面 | 様式を印刷し、納税地の所轄税務署へ持参または郵送。控えに受付印をもらう（郵送なら返信用封筒を同封） |

控えは必ず保管する。次回「出したかどうか」で迷わないために、
控えのスキャンを `2026_領収書` とは別に、届出書専用の場所へ保存しておく。

---

## 手順3: 届出書だけでは75万円にならない

75万円控除の要件は「**期限内のe-Tax申告** ＋（**優良な電子帳簿** または **デジタルシームレス保存**）」。
届出書は優良な電子帳簿ルートを使うという宣言であって、**帳簿の実体が伴っていなければ適用されない**。

優良な電子帳簿の要件:

- 訂正・削除の履歴が残る（または訂正削除ができない）システムで記録している
- 帳簿間の相互関連性が確保されている
- システム関係書類等の備付け・見読可能性
- **検索機能**（取引年月日／取引金額／取引先、範囲指定、2以上の項目の組み合わせ）

**最大の落とし穴** — マネーフォワード公式FAQに明記されているとおり、
優良な電子帳簿の検索要件を満たすには**仕訳に「取引先」を登録する必要がある**。
カード・PayPay・Amazon連携で自動取込した仕訳に取引先が入っているかを確認すること。
ここが空欄のままだと、届出書を出しても要件を満たさない。

## スケジュール

```
2026年9月    会計士に「届出書を出しているか」を確認     ← まずこれだけ
2026年10-11月 MFの設定確認（優良な電子帳簿の保存設定＋仕訳の取引先登録）
2026年12月   届出書を提出（法定期限は令和10年3月だが、忘れるので年内に）
2027年1月1日  要件を満たした状態で令和9年分の記帳を開始
2028年3月    令和9年分をe-Taxで期限内申告 → 75万円控除
```

## 未確認事項

**デジタルシームレス保存ルート**（請求書・領収書の電子取引データを会計ソフトに連携して保存）は
優良な電子帳簿の代替になるが、届出の要否・期限が別扱いである可能性を示す記述があり、確認できていない。
優良な電子帳簿ルートで足りるはずだが、会計士への確認事項に含めておく。
