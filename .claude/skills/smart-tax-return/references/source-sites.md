# 取得元サイト別の手順

保存先はすべて共通:
`/Users/<ユーザー名>/Library/CloudStorage/OneDrive-個人用/OneDrive/確定申告　スマカク/2026_領収書/YYYYMM提出資料/`

---

## CSVエクスポート機能があるサイト

素直にDLボタンを押せばよい。期間指定を対象四半期に合わせるのを忘れないこと。

| サイト | 導線 | 備考 |
|---|---|---|
| 楽天e-NAVI | 明細照会 → CSVダウンロード | ファイル名は請求月。4-6月利用分は 202605/06/07 |
| Vpass（三井住友・Olive・AMAZONマスター） | ご利用明細 → CSV | bot検知でブロックされやすい |
| MyJCB | ご利用明細照会 → CSV | 同上 |
| アメックス会員サイト | 明細 → CSV/Excel/PDF | 月次1ファイルずつでよい |
| PayPayカード会員メニュー | ご利用明細 → CSV | `detail<年月>(下4桁).csv` |
| PayPay残高（アプリ/サイト） | 取引履歴 → 期間指定 → CSV | 16口座ぶん。1口座1ファイル |
| Amazonセラーセントラル | レポート → ペイメント → 月別トランザクション | **CSVとPDFの両方**が必要 |

### ログインでブロックされたとき

三井住友（Vpass）と JCB は自動操作を検知してブロックしてくることがある。
**突破を試みない。** アカウントロックのリスクの方が大きい。

ユーザーに手動DLを依頼する。その際、
「どのサイトの・どのカードの・何月分を・どこに保存してほしいか」を具体的に伝えると1〜2分で終わる。

## CSVエクスポート機能が無いサイト

楽天PointClub と メルカリ には公式のCSV出力が無い。
画面を辿ってテキストを取り、こちらでCSVを組み立てる。

### 共通の型

```
1. 期間フィルタを対象四半期に設定する
2. 総件数を控える（「全163件」など）  ← 検算に使う
3. 全ページを get_page_text で取得する
4. 取得したテキストから行を起こして Python で CSV を書き出す
5. 行数が控えた総件数と一致することを確認する
```

**5番が要**。ページを1枚取りこぼしても気づかずに完成してしまうので、
必ず総件数と突き合わせる。`scripts/scrape_to_csv.py` にテンプレートがある。

### 楽天PointClub（ポイント履歴）

URL: `https://point.rakuten.co.jp/history/`

```
1. ページ下部の「さらに絞り込む」をクリック
2. 「期間の絞り込み」の開始/終了プルダウンを form_input で設定
   （find で combobox の ref を取り、値は "2026年4月" のような表示文字列）
3. 「この条件で絞り込む」をクリック
4. 総件数（"1 - 30件（全163件）"）を控える
5. 2ページ目以降は ?page=N に直接 navigate する
   → フィルタはセッションに保持されるので再設定不要
6. 各ページで get_page_text
```

出力する列:
`日付, サービス, 内容, ランクアップ対象, 区分, ポイント数, 備考`

区分は `獲得` / `獲得(期間限定)` / `獲得（失効）` / `利用` / `利用完了` / `チャージ(キャッシュ)` / `キャンセル`。
失効分はマイナス値で入れる。

**名義ごとに別アカウント**。TAKUYA と KAORI でログインが違う。
ページ右上の「ポイント口座番号」を見れば、今どちらのアカウントかを判別できる。
別名義の分を求められたら、まずこの番号で切り替わっているか確認すること。

### メルカリ（売上履歴）

URL: `https://jp.mercari.com/mypage/listings/sold`（マイページ → 出品した商品 → 販売履歴タブ）

```
1. 「表示期間」プルダウンで年を選ぶ（年単位でしか絞れない）
2. get_page_text で一覧を取得
3. 対象四半期の「購入完了日」の行だけを抜き出す
4. 各行の商品リンク（/transaction/<商品ID>）から購入日時など詳細を補う
```

一覧に出るのは:
`商品タイトル, 商品価格, 販売手数料, 送料, 他費用, 税率, 販売利益, 寄付, 購入完了日`

取引詳細ページを開くと `購入日時` と `商品ID` が追加で取れる。

過去にユーザーがブラウザ拡張で作ったCSVには `出品日時` `更新日時` の列があるが、
これは公式画面からは取得できない。列が減ることを報告し、必要かどうか確認する。

## Apple Gift Card 関連

05.AppleGiftCard には「AppleGiftCardを利用した領収書のみ」を入れる。
Apple からの請求メールを検索して、支払い方法が Apple Gift Card / Apple Account 残高のものだけを選ぶ。
クレカ払いのものは対象外。

ファイル名は Apple の請求書番号そのまま（`MC43517920.pdf` 等）。
四半期をまたいで同じ請求書を入れないよう、前四半期のフォルダと突き合わせる。
実際に `MC43517920.pdf` が1-3月分と4-6月分の両方に入っていた事例がある。

## 現金レシート（06）

- **1画像1枚・正面向き**で撮影する。まとめPDFは不可。
- 対象四半期の現金払いレシートすべて。
- 前四半期から持ち越しになっているレシートがあれば、それも今回に含める。

ここは自動化できない。ユーザーに撮影・アップロードを依頼する部分なので、
「何が必要か」を具体的に伝えるところまでが仕事。
