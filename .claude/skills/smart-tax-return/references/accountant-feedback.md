# 会計士（スマート確定申告）への連絡文

## 基本の型

指摘メールの番号と見出しをそのまま流用する。会計士は自分が書いた順に照合するので、
順番を変えたり項目をまとめたりしない。

```
お世話になっております。<氏名>です。

ご指摘いただいた◯点につきまして、対応が完了しましたのでご報告いたします。


■①（指摘の見出しをそのまま）

（対応結果）
（そう言える根拠を1行）


■②…

（同上）


■その他、あわせて修正した点

・（指摘外だが直したこと）


■◯点ご教示ください

（判断がつかず会計士に投げる項目。無ければこの節ごと省く）


お忙しいところ恐れ入りますが、ご確認のほどよろしくお願いいたします。

<氏名>
```

## 各項目の書き方

**「対応済み」で終わらせない。**
会計士は本当に直っているかを確かめたい。確かめる材料を渡す。

| 悪い例 | 良い例 |
|---|---|
| 解除済みです。 | 解除済みです。現在の連携は銀行5件・クレジットカード11件の計16件のみで、楽天市場・Yahooショッピングは登録されておりません。 |
| 提出しました。 | 4月・5月・6月それぞれのCSVとPDF、計6ファイルを提出済みです。（ファイル名を列挙） |
| 重複を直しました。 | 同一口座の履歴がCSV形式とNumbers形式で二重に入っておりました。Numbers版7件を「不要データ」フォルダへ移動し、現在は17ファイル（1口座1ファイル）です。 |

**指摘が間違っていた／既に済んでいた場合**も、正直に書く。
「作業しました」と取り繕わず「確認したところ既に◯◯でした」と書く。

**ファイル名は正確に全部書く。** 会計士がフォルダを開いて照合するときの手がかりになる。

## 「その他、あわせて修正した点」

指摘されていないが作業中に見つけて直したものを列挙する。
黙って直すと、会計士が前回見た状態と食い違って混乱のもとになる。

書くべきもの:
- 提出状況報告シートの記載訂正（どの行をどう変えたか）
- 期間違いで別フォルダへ移したファイル（判断根拠の日付も添える）
- 追加提出した資料

## 「ご教示ください」に回す基準

こちらで判断できないものは、推測で埋めずに会計士へ投げる。投げるときは
**何が分からないのか・何は分かっているのか**を具体的に書く。

```
03.PayPay履歴に「PAYPAY<下4桁>_20260401-20260630 (1).csv」という
ファイルがございますが、どの口座のものか特定できず、
提出状況報告シートへの記載ができておりません。

内容は4〜6月のYahoo!ショッピングにおけるPayPayポイント取引14件です。
1〜3月分の提出資料にも同番号のファイルはございませんでした。

シートに追加すべきか、提出対象外として不要データへ移すべきか、
ご教示いただけますと幸いです。
```

「分かりません」だけでは会計士も答えられない。調べた範囲を示す。

## 送信前にユーザーへ確認すること

連絡文は**ユーザー本人が送る**もの。事実でない記述が混ざると本人が困る。
以下は必ず本人に確認してから書く。

- **利用の有無**（メルペイを使ったか、現金レシートが手元にあるか）
- **取引がゼロだったのか、取得できていないだけなのか**
  （明細サイトにアクセスできず未取得の月を「利用なし」と書かない）
- **口座やカードの名義・番号**

こちらで確認できたのは「Driveにファイルが無いこと」だけであって、
それは「取引が無かったこと」の証明にはならない。この区別を曖昧にしない。

草案を出すときは、**確認できていない箇所を明示**して渡す。
