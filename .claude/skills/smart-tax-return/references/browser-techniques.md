# Google Drive のブラウザ操作

Drive の MCP コネクタは別アカウントに繋がっていてスマート確定申告の共有フォルダが見えないため、
Chrome拡張（`mcp__claude-in-chrome__*`）で操作する。

以下は実際に何度も失敗して確立した手順。**先に読んでから操作したほうが確実に速い**。

---

## フォルダの中身を列挙する

Driveの一覧は仮想スクロールで描画されるため `get_page_text` はほとんど何も返さない。
代わりに DOM の属性を直接読む。これが決定的に速い（1フォルダ1コールで全件取れる）。

```js
Array.from(document.querySelectorAll('[data-id]'))
  .map(e => e.getAttribute('data-id') + ' ## ' +
            (e.getAttribute('aria-label') || e.getAttribute('data-tooltip') || ''))
  .filter(s => s.split(' ## ')[1])
  .filter((v, i, a) => a.indexOf(v) === i)
```

`scripts/drive_inventory.js` に整形済みのものが置いてある。

### 押さえるべき癖

**1. フォルダとファイルで属性が違う**
- フォルダ → `aria-label`（末尾に「共有フォルダ」が付く）
- ファイル → `data-tooltip`（末尾にファイル種別が付く）

片方だけ見ると取りこぼす。必ず両方をフォールバックで見る。

**2. navigate 直後は DOM が空**
`navigate` の完了と一覧の描画完了は別。3〜4秒待つ。

```js
await new Promise(r => setTimeout(r, 3500));
```

待ちが足りないと空配列が返る。空が返ったら**フォルダが空なのではなく、まだ描画中**の可能性が高い。
もう一度同じJSを（navigateせずに）叩けば取れることが多い。この区別を間違えると
「空フォルダだ」と誤報告してしまう。

**3. `?` `&` `=` を含む出力はブロックされる**
戻り値にクエリ文字列っぽい並びがあると `[BLOCKED: Cookie/query string data]` になって中身が読めない。
ファイル名に含まれることがあるのでサニタイズする。

```js
.map(s => s.replace(/[?&=]/g, '_'))
```

ただし**このサニタイズをJSソース自体に適用しないこと**。
`[role="row"]` の `=` まで置換してしまい `SyntaxError` になった事例がある。
置換するのは「取得した文字列」だけ。

**4. `data-id` が長いと同じくブロックされる**
Googleドキュメント形式のファイルはIDが44文字あり、これもブロック対象になりやすい。
IDが不要なら名前だけ取る方が安全。

```js
[...new Set(Array.from(document.querySelectorAll('[data-id]'))
  .map(e => e.getAttribute('data-tooltip')).filter(Boolean))]
  .map(s => s.replace(/[?&=]/g, '_'))
```

### 複数フォルダを一気に回す

`browser_batch` で navigate と javascript_tool を交互に並べると、1コールで5〜6フォルダ回れる。
17枚のカードフォルダを見るのに、これで3コール程度に収まる。

```json
[
  {"name":"navigate","input":{"url":"https://drive.google.com/drive/u/3/folders/<ID>","tabId":<TAB>}},
  {"name":"javascript_tool","input":{"action":"javascript_exec","tabId":<TAB>,
    "text":"await new Promise(r=>setTimeout(r,3500)); ['<ラベル>'].concat([...new Set(Array.from(document.querySelectorAll('[data-id]')).map(e=>e.getAttribute('data-tooltip')).filter(Boolean))].map(s=>s.replace(/[?&=]/g,'_')))"}},
  ...
]
```

各結果の先頭にフォルダ名のラベルを入れておくと、どの出力がどのフォルダのものか分からなくなるのを防げる。

## フォルダを開く

**行のダブルクリックは使わない。** スクリーンショットから読んだ座標でダブルクリックすると、
数行上のフォルダに当たることが頻発する（実際に「三井住友Visa Infinite」を狙って
「MARRIOTT AMEX KAORI」に入る事故が複数回）。

代わりに、一度親フォルダで `data-id` を列挙してフォルダIDを取り、**URLに直接navigateする**。

```
https://drive.google.com/drive/u/3/folders/<フォルダID>
```

これなら100%狙ったフォルダに入る。navigate後は必ずタブタイトルでフォルダ名を確認する。

どうしても座標クリックが必要なら、いったんシングルクリック → スクリーンショットで
選択行が正しいか確認 → 改めてダブルクリック、の順にする。

## ファイルをアップロードする

```
1. 対象フォルダのURLへ navigate
2. 中身を列挙して「本当に空か」「既に何が入っているか」を確認  ← 省略しない
3. 「新規」ボタンをクリック（左上、おおよそ (67, 97)）
4. 「ファイルのアップロード」をクリック
5. find() で隠しの input[type="file"] を探す
6. file_upload() に macOS 絶対パスの配列と tabId を渡す
7. スクリーンショットでトーストの緑チェックと件数を確認
```

### 制約と失敗パターン

- **1回のfile_uploadは合計10MB未満**。超えるなら分割する。複数パスを配列で渡せる。
- **パスは macOS 側の絶対パス**（`/Users/<ユーザー名>/Library/CloudStorage/OneDrive-個人用/...`）。
  bashのマウントパス（`/sessions/.../mnt/...`）を渡しても見つからない。
- **「新規」→「ファイルのアップロード」の連続クリックでホームに飛ぶことがある**。
  頻発する。飛んだら慌てず、対象フォルダのURLへ navigate し直して手順3からやり直す。
- **find() が input を見つけられないことがある**。
  メニューがまだ開いている／既にホームに飛んでいる、のどちらか。
  スクリーンショットを撮って実際の状態を見てから対処する。
- **要素の ref 番号は毎回変わる**。前のコールで得た ref を使い回さず、都度 `find()` する。

### 拡張機能の一時エラー

「Chrome extension disconnected」「Script injection timed out」は一過性のことが多い。
同じコールをもう一度叩けば通る。原因究明に時間を使わない。

## ファイルを移動する（不要データフォルダへの退避）

重複ファイルは削除せず `不要データ[使用しないフォルダ 提出対象でない資料はこちらへ]` へ移す。

### 手順

```
1. ファイル行をクリックして選択（1件のみ）
2. `z` キー → 上部に「1個選択中」ツールバーが出る
3. ツールバーの移動アイコン（左から4番目、x≈655 y≈249）をクリック
4. 「候補」タブから `.04-06月分(7月末まで期限)` をダブルクリックして中に入る
5. 一覧の適当な行をクリックしてフォーカスを移し、↓キーで「不要データ」まで下る
6. 「不要データ」行をクリック → 右下の「移動」
7. 「アクセスできるユーザーを変更しますか？」→「移動」で確定
8. フォルダを再列挙して件数が減ったことを確認
```

### 致命的な制約：複数選択が効かない

**Driveの複数選択は自動操作ではまったく反応しない。** 試して駄目だったもの:

- Cmd+クリック / Ctrl+クリック → 最後の1件しか選択されない
- Shift+↓ → 選択が解除される
- 行アイコン部（x≈315）のチェックボックス → ホバー状態にならず出てこない
- 列ヘッダでのソート → クリックが効かない

結果、**1件あたり8〜10操作**かかる。件数が多いときは所要時間を正直に伝え、
手動（人間ならCmd+クリックで一括選択でき、1フォルダ30秒）を選んでもらうほうが速いことがある。

### ハマりどころ

**移動アイコンの座標がズレると共有メニューが開く。**
x≈565 は「共有」で、押すと Gmail / Meet のメニューが出る。Escapeで閉じて選択し直す。
アイコンは左から: 共有(565) / ダウンロード(610) / **移動(655)** / 削除(700) / リンク(747)。

**ダイアログの縦位置が毎回わずかに変わる。**
ファイル名が2行になると全体が下にずれる。座標を固定で持たず、都度スクリーンショットで確認する。

**「候補」タブの並び順が毎回変わる。**
直前に使ったフォルダが上に来るので、`.04-06月分` が1行目とは限らない。必ず見てからクリックする。

**確認ダイアログを閉じ忘れると次が始まらない。**
「アクセスできるユーザーを変更しますか？」の「移動」を押していないのに次のファイルへ進むと、
件数が減らないまま空振りする。移動後は必ず再列挙して件数を確かめる。

**ダイアログ内リストのスクロールも効かない。**
行をクリックしてフォーカスを当ててから↓キーで動かす。

## Googleスプレッドシート（提出状況報告シート）を読み書きする

シートは**canvasで描画されている**。DOMにセルの値が存在しないので、
`get_page_text` も `querySelectorAll` も使えない。gvizエクスポートもCORSで弾かれる。

**読むにはスクリーンショットしかない。**

### 目的のセルまで移動する

左上の名前ボックス（x≈50 y≈130）にセル参照を打ち込むのが唯一確実な方法。
グリッドはマウススクロールに反応しない。

```
名前ボックスをクリック → "L158" と入力 → Return
```

横に長いシートは、右の列を画面に入れるために少し右のセル（例 `R34`）へ飛ぶとよい。

### 読みやすくする

ズームを150%にすると「ー」「CSV」「画像」「連携」の判別が確実になる。
100%だと潰れて読み違える。ツールバーのズーム欄（x≈232 y≈87）から変更する。

### セルに値を入れる

**多くのセルはプルダウン（データの入力規則）付き。** 文字を打ち込んでも入らない。

```
1. セルへ移動
2. セル右の▼をクリック
3. 選択肢（連携 / csv / 画像 / ー / ○）をクリック
```

同じ値を横に展開したいときは、1つ入れてから Cmd+C → 名前ボックスで範囲指定 → Cmd+V が速い。

タブ区切り文字列を `type` で流し込む方法は、プルダウン付きセルでは効かないので使わない。

### どの値を選ぶか

**実際に提出したファイルの形式に合わせる。** カード会社ごとに決まっている。

| 提出物 | シートの記載 |
|---|---|
| CSVで提出したもの（楽天カード、PayPayカード、Vpass系 等） | `csv` |
| **PDFで提出したもの（JCB、AMEX系）** | **`画像`** |
| MF連携で明細が取れているもの | `連携` |
| 該当する取引が無かったもの | `ー` |

JCBとAMEX系はPDF提出なので `csv` ではなく **`画像`**。ここは実際に取り違えた箇所。
迷ったら該当フォルダを開いて拡張子を見る。

## Googleアカウントの切り替え（u/N が変わる）

DriveのURLに含まれる `u/3` などの数字は**ログイン中アカウントの並び順**で、
セッションやタブによって変わる。同じURLでも別タブで開くと
「アクセス権が必要です」になることがある。

その場合は `u/0` `u/1` `u/2` … と順に試して、タイトルがフォルダ名になるものを探す。

```
https://drive.google.com/drive/u/2/folders/<ID>
```

**「アクセス権限をリクエスト」は絶対に押さない。** フォルダ所有者（会計士）に
不要な承認依頼が飛ぶ。

## フォルダを新規作成する

```
1. 「新規」→「新しいフォルダ」
2. find() でダイアログのテキスト入力の ref を取得
3. form_input() で値を直接セットする   ← type アクションは使わない
4. スクリーンショットで入力内容を確認
5. 「作成」をクリック
```

`type` アクションはこのダイアログでは取りこぼしが多い。
`form_input` は DOM に直接値を入れるので確実。同じ理由で、
プルダウンの選択も `form_input` を使う（後述のサイト側フォームでも同様）。
