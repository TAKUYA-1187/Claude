# 投資家プロフィール（2026年4月時点）

## 基本情報
- 年齢: 45歳
- 世帯年収: 1,300万円
- 金融資産: 1,500万円
- 勤続年数: 15年
- 持ち家: あり（住宅ローン残金900万円）

## 融資力分析
- 想定借入可能額: 約8,000万〜1億2,000万円（年収の8〜10倍ベース）
- フルローン可能性: 「属性優良」区分（年収1,000万円超・勤続15年・持ち家）
- 自己資金: 諸費用（物件価格×6〜8%）は現金用意が必要
  - 5,000万物件なら諸費用約300〜400万円
  - 1億円物件なら諸費用約600〜800万円
- 住宅ローン残金900万円は与信に影響するが、年収比で問題なし

## フルローン戦略
### 狙うべき金融機関
1. **地方銀行（物件所在地の）** - 共同担保なしでも融資実績あり
2. **信用金庫** - 地元密着、柔軟な審査
3. **横浜銀行・千葉銀行・スルガ銀行（慎重に）**
4. **日本政策金融公庫** - 新築・利回り安定物件向け

### 共同担保戦略
- 自宅（持ち家）を共同担保に入れることでフルローン率UP
- 自宅の残債900万円を差し引いた評価額がプラスなら有効

## 物件選定基準
| 項目 | 条件 |
|------|------|
| 物件種別 | 一棟木造アパート（新築・築浅）または一棟RC |
| 価格帯 | 3,000万〜1億円 |
| 表面利回り | 8%以上（新築）/ 10%以上（中古） |
| エリア | 政令指定都市・地方中核都市の駅近 |
| 築年数 | 新築〜築10年以内（融資期間確保） |
| 戸数 | 6戸以上（空室リスク分散） |

## 資産拡大シナリオ
- 1棟目: 5,000万〜8,000万円（フルローン or 頭金500万以内）
- 2年後: 1棟目評価上昇 → 担保に入れて2棟目
- 5年後: 3棟体制、家賃収入500万/年超を目指す
